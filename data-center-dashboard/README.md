# DC-01 · 机房运行态势

在固定 1920 × 1080 的控制台中巡检 4 排 6 列共 24 台机柜，查看温度、负载、电流和数据流。场景以 CSS 3D 搭建，使用 Canvas 绘制动效和趋势图，再用 2D 面板查看机箱的端口、盘位、风扇与电源。

[在线演示](https://fanhuayishiy.github.io/ai-demo/data-center-dashboard/)

## 本地运行

用 Chrome 或 Edge 打开 `index.html` 即可离线运行。按 **1–5** 切换视角，点击机柜查看详情，进入单柜后点击设备即可继续查看前面板和机箱内部。页面数据均为演示数据。

## 主生成提示（原文）

```text
一、页面形式
做一个单文件HTML机房可视化页面，画布固定1920X1080，深色科技风(底色#04080f，主光青色#22d3ee)。
不引入Three.js，不加载任何3D模型文件，用CSS 3D的transform 搭场景。
二、场景内容
一个[4排x6列=24台】机柜的机房，柜子之间有通道，地面上画通道线;
配【若干台精密空调、配电柜】，顶部有桥架和灯带，远处墙面有门。
三、五层视角(重点)
场景外层放一个容器当“相机”，切视角只改这个容器的transform，里面的机柜一个都不要动。
要五层，一层比一层近，每层回答一个追问:
1上帝视角
-俯视全场24台机柜，看整体势态;
2第一视角
--镜头压到人眼高度，站在冷通道里往深处看;
3单柜视角
--柜门打开，看到每台设备是服务器、交换机、存储还是刀箱，交换机画端口阵列、服务器画盘位，设备右缘拉线缆进竖直理线区再上桥
架，左边配42U刻度尺;
4单机视角
点单台设备，出机箱面板:盘位、端口、状态灯、温度功率;
--掀开盖子看机内:双CPU核心点亮、DIMM内存槽、风扇墙、双电源、盘位背板、进风出风温度。
5机内视角
30只做前三层:后两层不要放大30场景，柜内标签放大九倍还是糊，改成2D高精面板叠在上面、场景退成暗背景，清晰度优先。
切换要有1秒左右缓动飞行，不要硬切。右上角显示视角名，配五个按钮，键盘1-5也能切。
四、四种数据模式
顶部分四个按钮:温度/负载/电流/数据流。切换时改变机柜顶面的颜色和图例:
温度用五档色阶(正常青、凉绿、偏热黄、注意橙、超过37°C红);
负载用百分比分档;电流显示单柜安培数;数据流模式不看颜色，改成地面上有光点在流动。
五、布局
顶部标题栏+7个KPI指标条;左列放分区温度和实时告警;右列放选中机柜的详情和供配电;
中间是3D视口;底部三张图:回风温度趋势、总电流、各柜负载柱状。
六、交互
点任意机柜，右侧详情跟着变(进出风温度、负载率、电流、功率、跑的业务)。
在单柜里点某台设备，直接再进一层到单机;再往下到机内，全程跟着同一台设备走。
选中的柜子和设备都要有高亮边框。
七、硬要求
1数字必须自洽:标题说24台，下面分档相加就必须是24，不能出现25或23。
2单个机柜用5个面就够:顶面、正面、左右侧面、底面。背面永远背对相机，不要画。
3柜深必须小于柜间距，否则相邻机柜会穿模，屏幕上就是一堆交叠色块。
4上帝视角的动效要画在屏幕空间:光柱、雷达、数据流弧线一律用canvas叠在最上层，不要画进3D场景里，否则一定被机柜和地板遮挡。
5页面里所有数据都是演示示意，不许出现真实企业名和真实地址。
```
