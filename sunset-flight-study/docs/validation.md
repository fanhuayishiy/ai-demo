开发期发现的海面 GLSL 保留字错误已修复，并重新查看海面显示。相机竖屏越过海平面的问题已通过纯函数测试和竖屏画面复查。浏览器缓存恢复由真实 EventTarget 生命周期回归测试覆盖。

全屏取决于宿主浏览器允许；未测量真实手机 GPU 帧率。对 README 的导航被内嵌浏览器拦截，因此没有宣称实际验证 BFCache 恢复；其挂起/恢复分支由自动化测试覆盖。没有声称跨浏览器或逐镜头素材一致性。
