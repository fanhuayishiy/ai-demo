请直接创建并验证一个完整、可运行的中文 Web3D 项目，名称为「夕空飞行 · Just breathe」。交付实际源码、启动说明和测试结果，不要只给概念、设计图或伪代码。合理自行决定未指定的细节，无需等待我逐项确认。若附有参考视频或截图，以附件的飞机比例、配色、云海层次和构图为视觉依据；没有附件时按下述说明实现，不要声称看过未提供的素材。

一、技术和整体目标
使用 Vite 7、Three.js 0.180、原生 JavaScript ES Modules、HTML/CSS，Node.js 20.19+ 或 22.12+。提供 npm install、npm run dev、npm test、npm run build、npm run preview；测试使用 node --test。默认页面是可操控的实时三维夕阳飞行，不是背景视频、静态截图或二维动画。飞机、云、海、航线和特效以程序建模/着色器生成，不依赖远程模型、字体、纹理，不需要后端。

二、默认夕空场景
采用温暖、安静、手绘动画电影感的非官方飞行致敬设计。主角是奶油白低置单翼飞机，约13米翼展、椭圆翼尖、弧面机身、绿色翼尖和绿白红圆形翼徽、三色尾舵、开放座舱、小飞行员、鼻端旋转螺旋桨。它不是红色水上飞机，也不是双翼机。使用三阶赛璐璐明暗、细梅紫轮廓、柔和接缝、哑光挡风玻璃，避免塑料高反光。机身参考色：基础 #ddd1bf、受光 #fff1c4、阴影 #827098；绿色 #277866。

环境是橙金色地平线、玫瑰色过渡与深紫天顶，夕阳方向约(-0.65,0.2,-0.7)。天空参考色 #ffbd71、#d98180、#382647。紫色立体云海要有前中后景、多层明暗和金色边光；用隐式曲面/Marching Cubes 等生成连成整体的雕塑状云团，不要把所有云做成平面贴图或明显的球串。下方是梅紫海面和细碎暖金倒影，保留深度雾、轻量纸感与克制柔光，不要全屏模糊。飞机居画面偏右下，前方留出天空和云的空间；中央常驻小写白色「just breathe.」，左上角是小字「SWALLOW ／ A FLIGHT STUDY」。不显示短视频水印或账号结尾。

三、航线和电影运镜
默认自动播放24秒无缝循环：0–6秒尾随、6–12秒剪刀、12–18秒回旋、18–24秒俯冲。航线有真实曲率变化、爬升和下降，飞机朝向由轨迹切线决定，侧倾对应转弯；螺旋桨持续旋转。默认镜头靠近机尾并略高，能看到上翼面，约48°视场，随飞机适度滚转，地平线有明显倾斜。四段是连续运动，不是生硬瞬移切镜；24→0也必须平滑。使用确定性时间采样和四元数，暂停、重播、拖动时间轴及跳段得到一致姿态。两条半透明翼尖气流沿历史轨迹延伸，疏朗的周边速度线增强飞行感，不能变成粗白实心管或闪烁断带。

四、键盘驾驶——优先保证手感
W/↑向屏幕上方、S/↓向下、A/←向左、D/→向右，短按微调、长按持续移动，仍沿电影航线自动前进，不是无限自由飞行。首次输入在0.4秒内平滑接管为水平稳定尾随视角：基于航向水平分量，后退34米、抬高8米、FOV 52°、镜头滚转归零。过渡必须保留飞机原来的屏幕构图锚点，不能先自动居中导致第一次左/右输入看起来反向。横竖屏均需正确。

手动水平/垂直速度分别为16/10米每秒，位置限制±20/±12米；速度及姿态的指数响应系数均为24，按帧时间积分，斜向输入归一化。侧倾目标为横向输入×0.52弧度，俯仰幅度为0.24弧度，方向必须符合上升/下降；松开迅速停稳，保留已移动位置。相机只跟随55%的手动位移，让剩余45%形成可见屏幕移动。非常短的按下/松开也至少采样75毫秒有效输入，不依赖操作系统按键重复，不让长按松开后继续堆积输入。

提供亮起的方向键指示、边界提示和「回到航线」按钮。G恢复自动航线；重播、跳段和切换机位也重置手动状态。暂停时不能驾驶，失焦/隐藏页面清空按键。时间轴、音量、下拉选项、输入框及弹窗拥有焦点时不抢方向键；按钮保留空格/回车原生操作，处理输入法和组合键。自由观察允许拖动旋转、滚轮或双指缩放，勿因手动接管破坏观察控制。
