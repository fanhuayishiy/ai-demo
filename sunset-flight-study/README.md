# 夕空飞行 · Just breathe

使用 Three.js 制作的可交互 Web3D 飞行场景。默认版本根据提供的夕阳飞行视频设计：奶油白单翼机、紫色立体云海、橙金天空、贴尾滚转运镜与翼尖气流。模型、环境、轨迹与引擎音效由程序生成；视频里的配乐已识别为 **BAANDIT! — rumination**，默认接入艺术家发布的 SoundCloud 官方播放器。不播放视频作为背景。

原来的《红猪》日间双机致敬版本保留在 `?scene=classic`，也可点击页面右上角「日间空战」进入。

[在线预览](https://fanhuayishiy.github.io/ai-demo/sunset-flight-study/dist/) · [当前版本复现提示词](./docs/RECREATE_PROMPT.zh-CN.md)

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。如果默认 5173 端口已被占用，Vite 会自动使用下一可用端口。本次预览运行在 http://127.0.0.1:5174/ 。

```sh
npm test         # 自动化测试
npm run build    # 输出 dist/
npm run preview  # 预览生产构建
```

请通过本地服务访问，不要直接双击 index.html。使用支持 WebGL 2 的现代 Chrome、Edge、Firefox 或 Safari；如无法显示，请开启浏览器硬件加速。

GitHub Pages 使用根目录的 `sunset-flight-study/dist/` 静态产物，不在服务端执行构建。`vite.config.js` 使用相对 `base: "./"`，支持合集子目录部署；发布源码改动后请重新构建并一起提交 `dist/`。

## 体验内容

### 默认 · 夕空飞行

- 低置椭圆机翼、奶油白机身、绿色翼尖与圆形翼徽、三色尾舵、开放座舱和鼻端螺旋桨。
- 真实三维雕塑云群，紫色明暗色阶与金色边光；橙金天空与梅紫海面的细碎倒影。
- 24 秒连续循环：尾随、剪刀、回旋、俯冲。镜头贴近机尾，飞机位于画面偏右下，地平线随动作滚转。
- 两条按飞行历史采样的透明翼尖气流，轻量高光柔光，居中的 `just breathe.` 字幕。
- 底部常驻操作栏：上一段、播放/暂停、重新开始、下一段、机位切换。点击「显示控制」或按 H 展开完整时间轴和画质设置。
- 键盘驾驶：WASD 或方向键短按微调、长按连续移动，侧倾/俯仰随输入变化，松开快速停稳。首次接管约0.4秒过渡到水平稳定的尾随视角，保留原屏幕构图，不因镜头居中造成反向移动；仍沿参考航线自动前进。按键指示会亮起，到达移动边界会提示；G 或「回到航线」恢复电影航线，分镜/机位切换及重播也会重置。
- 打开默认夕空页面即播放动画，首个画面成功渲染后自动启用原版配乐：**rumination — BAANDIT!**，约 1 分 56 秒，默认选中「原版整曲 · 在线」，音量35%。通过 SoundCloud 官方嵌入播放器流播，播放器就绪后请求播放；有声自动播放仍受浏览器限制，受限时点击内嵌播放器的播放键，再点回画面驾驶。暂停飞行或切换到后台时暂停，恢复后续播，结束后循环。音乐与24秒画面循环独立，不变速、不随每个分镜重头播放；用户主动关闭后不会被后续帧自动重开。
- 本地备用：选择「视频片段 · 本地」，使用从提供 MP4 中无重编码提取的 AAC 立体声音轨，约15.44秒。它明确标注为片段，不是完整原曲。切换音源先停止旧音源，保留音量和开关意图，不会同时叠播；官方播放器无法联网时不会偷偷换成片段。
- 点击「官方播放器 · 收起」可减少播放器占用，曲名、作者和配乐控制仍保留，音乐继续播放。桌面展开时位于左侧；若需要播放器内的播放按钮，再点击展开。

参考视频约 16.43 秒，末尾账号画面未使用。飞行动作改编成可拖动、可观察的 24 秒循环，并非逐帧复制；不显示平台水印或账号信息。备用片段保留视频中已混合的声音。

### 曲目来源

- [艺术家 SoundCloud 原曲](https://soundcloud.com/user-133547811/rumination)，上传者 prod.BAANDIT；应用使用其官方播放器。
- [艺术家 Bandcamp 发行页](https://baandit.bandcamp.com/track/rumination)，发行日2023-07-23，数字下载需付费。
- [Shazam 识别结果](https://www.shazam.com/track/672983150/rumination)，曲目ID672983150，ISRC QZNWV2399079。两段独立频谱指纹均匹配，时间/音高偏差接近零；不是《红猪》电影配乐。

应用不购买、不下载或再托管整首原曲，默认夕空首帧显示后加载 SoundCloud SDK 和官方 iframe，并尝试自动播放。音乐权利归原作者所有；官方流播需要网络且受平台、地区和浏览器策略影响。公开使用本地片段或自行托管全曲前，需另行确认适用授权。

仓库的 MIT 许可仅涵盖可授权的项目代码，不授予第三方音乐的权利。视频提取片段 `src/assets/reference-soundtrack.m4a` 及其构建副本不在 MIT 授权范围内；原始参考 MP4、视频截帧和含本机临时路径的素材分析脚本不随此发布包提交。

### 可切换 · 日间空战

- 红色飞行艇：船形机身、高置单翼、独立发动机、木质螺旋桨、开放座舱、飞行员、翼端浮筒、三色尾舵。
- 蓝色双翼机：上下机翼、撑杆与张线、径向发动机、双浮筒、独立追逐航线。
- 72 秒循环空战，六段运镜：掠海、追逐、交错、爬升、回旋、远航。短促曳光弹只在目标位于前方时出现。
- 电影运镜、追随机位、自由观察；播放、暂停、重播与时间轴拖动。
- 三阶赛璐璐飞机：朱红亮面、酒红暗面、细色轮廓与哑光玻璃，保留船体曲面和机翼细节。
- 本地生成的手绘云纹理、蓝青海面色层与稀疏浪痕、石灰岩海岛；轻量纸感处理，不使用全屏模糊。
- 默认静音；点击音效按钮启用程序合成的引擎和海风声音。
- 响应式布局、流畅画质、键盘操作和减少动态效果支持。

## 操作

| 操作            | 控制                               |
| --------------- | ---------------------------------- |
| 播放 / 暂停     | 空格或左下播放按钮                 |
| 夕空飞机移动    | W/↑ 上、S/↓ 下、A/← 左、D/→ 右；按住可连续移动 |
| 回到自动航线    | G 或「回到航线」按钮                |
| 切换分镜        | 默认 1–4；日间版 1–6；或底部分镜   |
| 从头播放        | R 或重播按钮                       |
| 开关音效        | M                                  |
| 夕空配乐开关    | P 或底部配乐按钮                    |
| 配乐音源        | 曲目卡右侧选择原版整曲或视频片段    |
| 配乐音量        | 底部音量滑块，0–100%                |
| 夕空机位        | 底部机位按钮：电影 → 追随 → 自由    |
| 全屏            | F（需要浏览器支持）                |
| 隐藏 / 显示控制 | H 或夕空版右上按钮                 |
| 观察模型        | 自由视角下拖动旋转，滚轮或双指缩放 |

点击画面后即可使用键盘驾驶。暂停飞行时不移动，切换窗口时会释放按键；水平/垂直移动限定在参考航线附近的±20/±12米范围，属于辅助驾驶，不是无限自由飞行。相机跟随55%的手动位移，留下45%的相对运动用于可见反馈。很短的按下/松开至少采样75毫秒的输入，不依赖系统按键重复。焦点位于时间轴、音量滑块、选项或文本输入时，方向键保留原生行为，不会同时移动飞机；按钮保留空格/回车的原生操作。

夕空版按明确的默认播放要求启动，不因系统减少动态偏好自动暂停；仍可随时按空格或播放按钮暂停。日间版保留原来的减少动态默认暂停行为。后台打开时等页面可见且成功渲染后再开始配乐，WebGL 初始化失败不会启动声音。

## 代码结构

- `src/scene-profile.js`：默认夕空与日间版的配置选择。
- `src/reference-aircraft.js`：夕空版程序化单翼机。
- `src/reference-flight.js`：24 秒循环轨迹、平滑追随机位与四段动作。
- `src/sunset-world.js`：隐式曲面云群、紫金色阶、周期天空与海面着色器。
- `src/reference-effects.js`：透明翼尖气流与周期性周边速度线。
- `src/aircraft.js`：两架程序化飞机及材质。
- `src/cel-material.js`：手工指定的三阶明暗、细轮廓与雾效。
- `src/world.js`：海面与天空着色器、云层、岛屿与照明。
- `src/painted-clouds.js`：确定性生成的 RGBA 云纹理，随观察方向转向镜头。
- `src/anime-renderer.js`：线性场景缓冲、纸感调色、夕空版高光柔光、一次屏幕颜色转换；支持画质、尺寸和资源释放。
- `src/flight.js`：可确定采样的飞行轨迹和六段分镜。
- `src/camera.js`：响应式镜头构图与海面安全高度。
- `src/combat.js`：前向射击判定。
- `src/playback.js`：时间轴状态。
- `src/audio.js`：按需启动的 Web Audio 引擎与风声。
- `src/music.js`：独立音量与音频生命周期；保留原合成器供已有测试使用，但夕空版不再选择合成音源。
- `src/original-music.js`：SoundCloud 官方整曲播放器，按需加载SDK/iframe、真实播放事件、暂停/音量/循环/失败重试/销毁处理。
- `src/video-music.js` / `src/assets/reference-soundtrack.m4a`：视频音轨按需加载、解码与本地 AAC 文件。
- `src/music-worker.js`：原合成器的后台生成模块，视频原声不使用它。
- `src/sunset-controls.js`：常驻按钮意图转发和播放/配乐状态同步。
- `src/pilot-input.js` / `src/pilot-motion.js`：按键生命周期、平滑位移与侧倾、跟随镜头和回航重置。
- `src/lifecycle.js`：页面离开与浏览器缓存恢复。
- `src/main.js` / `src/style.css`：渲染集成、交互与界面。

## 说明

这是程序建模的非官方致敬版，不使用官方模型或逐帧分镜。飞行动作为艺术化编排，不是空气动力学模拟。首次安装需要网络；场景本身不请求远程字体、模型或纹理。启用原版整曲时会请求 SoundCloud；选择本地视频片段可离线播放已打包的片段。
