# Sagrada Família · 圣家堂建造时间线

以巴塞罗那圣家堂为原型的程序化三维建筑展示。默认打开蓝调夜景，可以沿 1882—2026 年时间线查看主要建筑构件的生长过程，也可以查看包含 18 座塔楼的规划全貌。

[在线预览](https://fanhuayishiy.github.io/ai-demo/sagrada-familia/) · [单文件源码](./index.html)

## 功能与交互

- 诞生立面、受难立面、荣耀立面规划、中殿、后殿、回廊、中央塔群与宗徒塔的三维几何建模。
- 开孔石肋、斜置百叶、窗棂、彩窗、概括性雕塑群、彩色塔冠和果实尖顶。
- 1882—2026 年逐年滑块、关键年份节点、建造历程播放和未建轮廓。
- 日间与蓝调夜景切换，建筑投光、发光彩窗、塔冠柔光和公园照明同步变化。
- 鼠标拖动环绕、滚轮缩放、右键平移、点击建筑聚焦、预设特写与一键恢复全景。
- 触屏单指旋转、双指缩放和平移；手动控制时停止自动环绕。
- 静止时按需渲染，静态阴影缓存，重复构件合并或实例化。

快捷键：`D` 日间、`N` 蓝调、`O` 自动环绕、`R` 恢复全景、空格播放或暂停建造历程。选中时间线后，可用方向键逐年调整。

## 运行方式与技术栈

`index.html` 内含完整 HTML、CSS、JavaScript、建模与交互代码，无需构建，也不加载现成的完整圣家堂模型。使用 Three.js 0.170.0、OrbitControls 和 BufferGeometryUtils，通过 CDN 加载；字体通过 Google Fonts 加载，并提供系统字体回退。

联网后用支持 WebGL 2 的现代 Chrome 或 Edge 直接打开 `index.html`，或在仓库根目录运行：

```sh
python -m http.server 8000
```

然后访问 <http://localhost:8000/sagrada-familia/>。

## 史实、验证与边界

2026 年指耶稣塔外部落成，整座圣家堂仍有工程继续进行。“规划全貌”展示包括荣耀立面及其塔楼在内的设计愿景，不表示 2026 年已经全部建成，也不承诺全堂最终竣工日期。

时间线按公开里程碑组织，阶段之间的构件生长采用示意性插值。建筑比例与主要结构参考公开资料；局部雕像、雕饰和部分屋面构件为程序化概括性重建，并非测绘模型。周边街区、公园和水池为艺术化环境设计。

已在 Chromium 中检查本地直接打开、默认蓝调与加载页状态、昼夜切换、时间线与规划全貌、自动环绕与手动接管、预设特写、点击聚焦、缩放平移、窗口缩放及手机布局。预设中央塔特写已保留十字架顶部空间。静止状态验证未持续重绘；未将该结果等同于所有设备上的性能保证。

建筑细节

时间线应至少包含几个关键节点（如 1882 始建、1926 高迪逝世、1950 复工、1976 塔尖、2000 中央塔、2010 中殿、2026 完工），并允许用户自由选择任意年份。

切换年份时，建筑外观应平滑过渡或即时更新，清晰展示“从无到有、逐步生长”的建造过程。

为教堂设计完整、精致且富有美感的周边环境。可以自由加入元素，使教堂自然融入一幅具有空间层次的三维景观。
