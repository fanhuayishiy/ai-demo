# 三坊七巷 · 坊巷漫游

基于 Three.js 和真实 OpenStreetMap 街巷、建筑平面轮廓的交互式三维文化导览。白墙、瓦顶、窗棂、山墙和树木为风格化建模，并非摄影全景或测绘级实景模型。

在线预览：<https://fanhuayishiy.github.io/ai-demo/sanfang-qixiang-atlas/dist/>

## 主生成提示（原文）

> 根据网上的地图，实现一个3D的三坊七巷旅游全景图，要求可以交互、滚轮缩放，点击某个地点后，可以自动飞过去。

## 功能亮点

- 真实 OpenStreetMap 街巷与建筑平面轮廓：901 个建筑、107 段道路、294 个庭院内孔、19 个导览地点。
- 3D 白墙黛瓦古厝沙盘：道路、水体、公园、院落、马鞍墙、屋脊、窗棂、树木和街灯形成可读的街区层次。
- 支持左键拖拽旋转、右键拖拽平移、滚轮缩放，点击景点标签或左侧目录后相机平滑飞行。
- 支持景点搜索、名人故居/文化古迹/街巷筛选、3D/俯瞰视角、朝北、标签显隐和日夜切换。
- 内置五站空中漫游，可暂停、继续、手动跳转下一站或结束漫游；移动端支持触控操作。
- 所有近似坐标会显示“位置示意”，页面保留 © OpenStreetMap contributors 和 ODbL 许可入口。

## 运行与部署

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

以终端输出的本地地址为准。端口被占用时，Vite 会自动使用下一个端口。

```sh
npm run build
npm run preview
```

`dist/` 可部署到静态网站服务的根目录。地图数据、程序生成的材质和图标随项目打包，运行时不依赖第三方地图 API、在线字体或密钥。首次安装依赖需要网络。

GitHub Pages 直接托管提交后的 `dist/`：

```sh
npm ci
npm run build
```

在仓库根目录执行 `python3 -m http.server 8123` 后访问 `/sanfang-qixiang-atlas/dist/`，也可以使用 `npm run preview` 检查构建产物。

## 交互

- 左键拖拽旋转，右键拖拽平移，滚轮或工具栏缩放；触屏支持单指旋转、双指缩放和平移。
- 点击地图标签或景点目录，镜头平滑飞往对应地点并展示介绍。
- 按名称、街巷、地址或介绍内容搜索，可筛选名人故居、文化古迹和街巷。
- 支持三维/俯瞰视角、朝北、恢复全景、标签显隐及日夜切换。
- 五站空中漫游支持暂停、继续、下一站及结束；直接拖动地图会暂停漫游。
- 地图获得键盘焦点后，方向键平移，`+` / `-` 缩放，`Home` 恢复全景；`/` 搜索，`Esc` 关闭详情。
- 适配桌面、手机竖屏和低高度横屏，尊重系统的减少动画偏好。

## 数据及精度

使用 WGS84 坐标。街区原点为 `[119.2916, 26.085]`，场景 x 向东、z 向南，单位为米。901 个建筑轮廓、107 段道路及 294 个庭院内孔来自保存的 OSM 快照；19 个导览地点含逐点来源和精度标识。

小黄楼、二梅书屋及光禄吟台使用相应街段附近的近似位置，详情标注“位置示意”。虚线路线表示参观顺序，不提供实地步行导航。建筑高度、屋顶形式与装饰不是测绘数据。

完整来源和许可见 [sources.md](sources.md)。地图数据 © OpenStreetMap contributors，遵循 ODbL。

已验证：`npm run build`、生产静态资源加载、桌面/竖屏/低高度横屏布局、滚轮缩放、拖拽旋转、搜索筛选、点击飞行、俯瞰与日夜切换、空中漫游控制。

## 结构

- `src/main.js`：导览界面、相机飞行、交互、路线与标签投影。
- `src/district.js`：建筑轮廓建模、庭院、屋顶、实例化装饰与道路。
- `src/style.css`：响应式布局与视觉样式。
- `public/data/map.geojson`、`places.json`：随站点部署的地图数据。
- `public/data/osm-source.xml`、`prepare_map.py`：原始数据与转换脚本。
- `dist/`：GitHub Pages 使用的静态构建产物。

重新生成 GeoJSON：`python public/data/prepare_map.py`。更换地图范围后需要同步来源文档和 README 中的数据数量。
