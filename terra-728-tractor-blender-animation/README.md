# TERRA 728 · 现代四驱拖拉机精细建模与机械动画研究

成品是一台虚构命名的 **TERRA 728** 大型四驱 CVT 拖拉机概念模型：以现代农机的公开机械架构为参考，用 Blender 5.2.1 程序化建模，交付 1–360 帧、24 fps 的 15 秒机械演示动画，以及可编辑 `.blend`、通用 `.glb`、四张 Cycles 渲染图和一套浏览器交互查看器。

> 在线预览：<https://fanhuayishiy.github.io/ai-demo/terra-728-tractor-blender-animation/>
>

## 参考调研

造型与机械架构参考 [Fendt 700 Vario Gen7.1 官方产品页](https://www.fendt.com/int/agricultural-machinery/tractors/fendt-700-vario-gen7) 和 [官方技术参数表](https://api.fendt.com/techdata/GB/en/1551551) 的 728 Vario 列。用于确定比例关系的主要公开数值：总长 5516 mm、标准胎总宽 2650 mm、驾驶室高 3280 mm、轴距 2900 mm、前胎 540/65R34、后胎 650/85R38、7.5 L 发动机 1700 rpm 额定、后 PTO 540/540E/1000/1000E rpm。

从资料中提炼并落实到模型上的结构特征：

- **VarioDrive 四驱**使前轮明显小于后轮，而非等大四轮；本模型前胎半径 0.745 m、后胎 1.02 m，轴距放大到 3.00 m。
- **同心加压风扇（CAS）** 官方说明为独立液压驱动，因此冷却风扇拥有自己的旋转控制，动力不挂在发动机皮带上。
- **VisioPlus 驾驶室**要求大面积玻璃与右侧附加雨刷；内饰按 **FendtONE / Profi+ 控制台** 的层次建模为右扶手、多功能手柄、独立操纵杆、旋钮、双触屏与副座，而不是"一块屏加一把椅子"。
- 轮胎按官方胎号估算无载理论外径（前 ≈1.566 m、后 ≈2.070 m）确定胎体尺寸，交错 V 形花纹、胎肩、侧壁环带与凸起字标分别建为独立部件。

未获取正交蓝图或维修级装配图；隐藏结构、具体枢轴位置、配合间隙和局部管线路由均属概念设计。

## 建模内容

场景共 **1482 个对象、1363 个网格对象、228 217 个源顶点、25 种材质、35 个动画对象**。以真实米制创建，整体包在 `TERRA 728 | MASTER` 根节点下，部件按 `01 轮胎轮辋` / `02 传动与转向` / `03 机罩与服务面板` / `04 动力与冷却`、`04 • 全景驾驶室` / `05 翼子板踏步附件` / `06 后液压悬挂与 PTO` 分集合组织。名义外形约 **6.08 × 2.84 × 3.89 m**（第 1 帧、机罩闭合，含顶部架）。

**行走与传动**

- 四只独立车轮：车削胎体、多组斜向交错胎块、胎肩过渡、侧壁环带、凸起字标、锻造轮辋凹槽、10 孔螺栓圈与中心盖、气门嘴。
- 前后轮分别按自身半径计算角速度，同一地面速度下前轮转得更快；传动轴、前后桥壳、转向节与拉杆齐备。
- 左右前轮绕真实主销竖轴转向，转角采用 Ackermann 近似，前翼子板随转向节一同偏转。

**机罩与发动机舱**

- 多截面放样出的曲面机罩、腰部黑色通风口、前脸与散热器格栅、锐角双侧大灯、后视镜与多段支架。
- 舱内是有体积与连接关系的实体：发动机主体、冷却器薄片、独立液压驱动风扇与风扇罩、进气管路与箍带、滤筒、蓄电池、油箱与加注盖。
- 机罩绕后铰链开启，由两根带抛光活塞杆的气弹簧支撑；开启全程与风挡玻璃的相交面对数保持为 0。

**驾驶室与内饰**

- 实体门框与立柱厚度、透光玻璃、左侧后铰链车门（含把手与密封条整体旋转）、防滑登车踏步与独立金属扶手。
- 气动悬浮座椅带行程缓震、可折副驾驶座、橡胶风琴式方向柱护套与方向盘、中央横屏与右扶手屏、顶棚附加屏、出风口、液压拨杆、彩色按钮、三个踏板、车顶四角工作灯与两具旋转警示灯。

**后部液压与动力输出**

- 两根下拉杆、两根提升连杆与摇臂构成后三点机构，四段式抬升与回落。
- 提升油缸与机罩气弹簧均为真实伸缩副：活塞杆随两端点伸缩，安装误差最大 3.8 × 10⁻⁵ m，轴线方向偏差 1.3 × 10⁻⁷。
- 后 PTO 花键轴与演示联轴器、前部三点悬挂、液压快接头与软管、反光警示板。

## 使用文件

- `index.html`：Three.js r186 交互查看器，直接加载同目录 GLB。支持五个视点（整车 / 前端 / 侧视 / 后悬挂 / 驾驶室）、1–360 帧拖拽、六章节跳转、线框叠加与隐藏驾驶室顶棚。three.js 已随目录提供，不依赖 CDN。
- `TERRA_728.blend`：主文件，含可编辑部件、动画、五台相机、影棚布光与时间轴标记。用 Blender 5.2.1 或更新版本打开，按空格播放、小键盘 0 切相机。
- `TERRA_728.glb`：通用模型，1434 个网格、1472 个节点、34 个动画片段。已应用修改器、剔除摄影棚地面与灯光，保留命名部件与烘焙后的场景动画，可直接拖入支持 glTF 的查看器或引擎。
- `01_Hero.png`、`02_Rear_Three_Point.png`、`03_Engine_Bay.png`、`04_Cab_Interior.png`：Cycles 渲染的整车、后悬挂、机罩服务面与驾驶室剖视（后者隐藏顶棚）。
- `Validation_Summary.json`：场景统计、尺寸、动画、机械一致性与文件哈希摘要。
- `scripts/`：程序化建模、校验与资产导出脚本，见下。
- `vendor/`：本地 three.js r186 模块与 `THREE-LICENSE.txt`。

### 复现构建

```bash
blender -b --python scripts/build_tractor.py          # 重建场景并导出 .blend / .glb
blender -b output/TERRA_728.blend --python scripts/verify_scene.py   # 95 项断言校验
blender -b output/TERRA_728.blend --python scripts/publish_assets.py -- --export --render
```
