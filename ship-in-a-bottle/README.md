# 瓶中沧海 · 前进·梅利号

搁在木托架上的横卧玻璃瓶里装着一整片海：体素化的前进·梅利号绕珊瑚岛航行，红白灯塔的光束扫过浪尖，鲸鱼周期性跃身出水，水底沉着宝箱、沉锚与珊瑚。支持晴 / 多云 / 雨 / 雾四档天气、时刻滑杆与黎明-正午-黄昏-子夜跳转，按住 Space 掀起风暴。全部几何体与纹理由代码生成，Three.js r160 走 CDN，**单 HTML 文件直接打开**。

[在线预览](https://fanhuayishiy.github.io/ai-demo/ship-in-a-bottle/index.html)

## 主生成提示（原文）

> 用 WebGL（Three.js r160 CDN）创作一个体素微缩场景——瓶中沧海：一艘前进·梅利号在封闭于横卧玻璃瓶内的海洋上航行，输出为可直接在 Chrome 打开的单个 HTML 文件。
> 瓶与陈设：玻璃瓶身有菲涅尔边缘光与高光，软木塞 + 红蜡封 + 颈绳吊牌，搁在木托架上，置于木桌面（旁有旧书、黄铜望远镜），黄昏房间光氛围。
> 瓶内海洋：体素浪面在 GPU 上起伏、浪尖泛白沫；水面以下是整体铺满的渐变深水体（无海床），半透明可透视——水底沉着宝箱（金光）、沉锚、双耳瓶、珊瑚，气泡上升。珊瑚岛上有红白灯塔（旋转光束）、棕榈、暖窗小屋、码头与小艇、宝藏。
> 帆船：三桅方帆 + 红纹主帆 + 全套索具，绕岛航行；浮力物理：四点浪高采样驱动升沉/纵摇/横摇，带船艏飞沫与尾迹。空中：六只海鸥盘旋，积云在鸟与桅杆之上，鲸鱼周期性跃身出水，浮标、鱼群、螃蟹点缀——一切元素严格封闭在瓶内，任何视角不得越出轮廓。
> 交互：拖动环视（闲置自动恢复旋转）、滚轮缩放；按住 Space 掀起风暴——浪涌飞沫、瓶体在托架上摇晃而瓶内水面保持水平、闪电与乌云；延时摄影倍速（×4/×12/×1/暂停）驱动昼夜流转：太阳月亮移动、黎明正午黄昏子夜四段天色、子夜星空，夜晚灯火热光更浓。
> 技术：InstancedMesh 体素批渲染 + 自定义 shader（玻璃、水面顶点位移），目标 60 FPS。

## 功能亮点

**瓶与陈设**

- 玻璃瓶 LatheGeometry 旋转成型，自定义 shader 实现菲涅尔边缘光、双光源高光与随视角流动的窗光条痕；软木塞、红蜡封（带流挂泪滴）、颈绳吊牌（GOING MERRY）
- 双环木托架 + 木桌面，旧书、黄铜望远镜（三脚架）、油灯（暖光闪烁）、航海图与铜罗盘；黄昏房间光氛围

**封闭机制（核心）**

- 所有瓶内材质通过 `onBeforeCompile` 注入同一段瓶体 SDF 裁剪：世界坐标反变换回瓶局部，超出瓶身轮廓的片元直接 discard——任何视角下云、鸟、桅杆、雨丝都不会穿出玻璃

**瓶内海洋**

- 体素浪面：118×54 网格顶点着色器起伏，高度量化成台阶形成体素浪，浪尖白沫、岸边环岛碎浪、砖面微差与细波微法线粼光
- 渐变深水体：瓶内壁轮廓 lathe 成体，按世界水面高度切割（无海床），半透明透视出水底宝箱金光、沉锚、双耳瓶、珊瑚丛与上升气泡
- GLSL / JS 镜像同一波浪公式，四点浪高采样驱动帆船升沉、纵摇、横摇，船艏飞沫与粒子尾迹

**珊瑚岛与生物**

- 红白条纹灯塔 + 旋转光束（呼吸脉动）、棕榈、暖窗小屋（烟囱炊烟）、栈桥码头、岸边小艇、金堆宝藏、岩石草丛贝壳
- 三桅方帆 + 红纹主帆 + 羊首像 + 全套索具与横索，绕岛椭圆轨道航行；六只海鸥扑翼盘旋、积云漂在桅杆之上、鲸鱼 24 秒周期跃身出水（入水出水双溅花）、鱼群、螃蟹、浮标随浪

**天气与昼夜**

- 晴 / 多云 / 雨 / 雾四档平滑过渡：雨丝斜落瓶内、落水溅涟漪，雾气面片漂移（受瓶体裁剪），阴沉度统一驱动光照、天色、云色与曝光
- 按住 Space：浪涌 ×2、飞沫加剧、乌云聚拢、随机闪电（瓶内点光爆闪 + 玻璃/水面提亮）、瓶体在托架上摇晃而水面保持水平
- 时刻滑杆（昼夜色带轨道）+ 黎明/正午/黄昏/子夜跳转，×4/×12/×1/暂停延时摄影驱动太阳月亮、四段天色、子夜星空；夜晚灯塔、小屋暖窗、船尾提灯与桌上油灯燃得更旺

**交互与性能**

- 拖动环视（闲置 3.5 秒自动恢复旋转）、滚轮缩放（阻尼平滑）、移动端双指缩放
- InstancedMesh 体素批渲染（约 70 个 draw call）+ 自定义 ShaderMaterial（玻璃 / 浪面 / 深水体 / 天空 / 粒子），目标 60 FPS
- CDN 加载带超时重试与缓存穿透，失败时显示具体原因

## 验证与边界

- **封闭性**：瓶体轮廓以解析函数 `bottleInnerR(x)`（瓶身圆柱 + 肩部 smoothstep 收窄 + 瓶颈）在着色器中求值，所有瓶内容器统一注入裁剪，粒子与雨丝走各自 shader 内的同一段 SDF；船桅顶、云顶、海鸥轨道、鲸鱼跃身轨迹均按瓶内半径预留余量设计，风暴时轨道自动微收
- **物理直觉**：瓶体摇晃（±2.5°）时水面与船体保持世界水平，深水体按世界水面高度切割；浮力为四点浪高采样的运动学近似，非流体仿真
- **边界**：场景为艺术示意，非真实船模或海洋数据；雨 / 雾 / 闪电为程序化视觉近似；需联网加载 Three.js CDN，断网时显示失败原因
- 已在 Chrome 桌面端实测：黄昏 / 正午 / 子夜 / 风暴 / 雨 / 雾画面截图核验，倍速、暂停、时刻跳转、天气切换交互全通过
