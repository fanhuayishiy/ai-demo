# 栖居 · HABITAT

一个可以环绕探索、逐个控制灯光与家电的 3D 家庭前端项目。以温暖木色、低饱和绿色和清晰的空间层次组织交互，使用 React、TypeScript、Three.js 和 Vite 实现。

## 运行

建议使用 Node.js 22.6 或更新版本。首次运行：

```bash
npm install
npm run dev
```

打开终端显示的本地地址（通常是 `http://localhost:5173`）。

```bash
npm run build    # TypeScript 检查与生产构建，产物位于 dist/
npm run preview  # 本地预览生产构建
npm test         # 设备状态、场景与持久化测试
```

项目不依赖后端、账户、外部 3D 模型下载或 API 密钥；构建后的 `dist/` 可部署到静态站点服务。

## 使用方法

- 在三维空间按住鼠标左键拖动旋转，使用滚轮缩放；鼠标右键拖动平移。触屏可单指旋转、双指缩放和平移。
- 点击房间导航聚焦对应空间；使用视图控制切换全屋视角和俯视图。
- 自动墙体模式根据观察方向隐藏遮挡视线的墙面，也可切换显示或隐藏墙体。
- 点击三维模型中的灯具或家电，打开对应的设备控制菜单；也可从设备列表选择。
- 每个灯具有自己的开关、亮度和色温。客厅、主卧、书房和餐厨均包含多路独立灯光，操作会直接影响三维空间的照明。
- 电视、空调、窗帘、冰箱、抽油烟机、烤箱、热水器、洗烘机、扫地机器人和音箱都有独立设备状态；可用控制项取决于设备类型。
- 回家、观影、睡眠和离家场景会批量调整设备；冰箱在这些场景中保持运行。
- 设备设置会保存在当前浏览器的本地存储中，刷新后恢复；日间、黄昏和夜间环境用于观察不同照明效果。

## 户型与素材说明

用户未提供户型图与实拍照片，因此本项目采用**原创 108㎡ 示例户型**，没有将示例包装为真实房屋的照片重建。参考平面图位于 [`public/floorplan.svg`](public/floorplan.svg)，开发服务运行后可直接访问 `/floorplan.svg`。

| ---- | ----------- | ------------ | ----------- |
| 主卧 | -6 至 -2    | -4.5 至 0.6  | 4.0 × 5.1 m |
| 卫浴 | -6 至 -2    | 0.6 至 4.5   | 4.0 × 3.9 m |
| 书房 | -2 至 2.3   | -4.5 至 -0.8 | 4.3 × 3.7 m |
| 客厅 | -2 至 2.3   | -0.8 至 4.5  | 4.3 × 5.3 m |

墙体、门窗、软装、家具和电器使用程序化几何体及材质搭建；户型图是与示例空间分区对应的设计示意，不用于施工。后续收到真实尺寸与照片后，可在此基础上替换空间配置和家具模型。

## 项目组织

- `src/types.ts`：房间、设备、场景及三维组件接口。
- `src/data.ts`：房间与设备清单、场景状态转换、持久化状态读取及数据校验。
- `src/main.tsx`：React 应用入口。
- `src/App.tsx`：设备面板、房间导航、场景预设、弹窗与交互状态。
- `src/scene/HomeScene.tsx`：Three.js 渲染、射线拾取、相机控制与墙体可见性。
- `src/scene/house.ts`：户型、家具与家电程序化模型。
- `src/styles.css`：视觉样式、布局和响应式界面。
- `public/floorplan.svg`：可独立查看的示例户型图。
- `tests/home-state.test.ts`：设备数据和状态行为测试，使用 Node.js 内置测试器，无额外测试依赖。

三维物体与设备状态通过稳定的设备 ID 关联，React 管理交互状态，Three.js 更新对应实体和灯光。每个灯具都是独立设备，而不是整间房共用一个灯光开关。

## 功能边界

这是可独立运行的空间交互演示。设备控制、运行模式及功率数字均为**本地模拟**，不会连接或操作真实家电；功率是演示用额定参数，不代表真实电表读数。接入真实家庭设备时，应由独立后端处理身份认证、设备协议和状态同步，再将设备状态映射到现有设备 ID。

画面需要支持 WebGL 的现代浏览器；复杂三维渲染的流畅度受显卡、浏览器和设备性能影响。
