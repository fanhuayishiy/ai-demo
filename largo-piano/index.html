怎么练

页面默认自动演奏《小星星》，下落条和琴键会随旋律一起变化。浏览器允许时打开即播放；声音受限时点击一次「点击开始演示」。切换曲目会立即从头演奏所选曲目。开启等待模式后，在每组音符的起点冻结，按对所有亮键后继续；和弦可依次按对。条的长度表示时值，右侧显示应保持的拍数与秒数。当前版本检查音高，不考核实际按住的时长。

等待模式默认关闭，可随时开启练习。手动按键会暂停自动演奏，最后一个键松开 320 毫秒后恢复；按错会轻微闪红，可以继续试。静音仍保留下落条与键位提示。切换页面、窗口失焦会暂停并释放按键。

提前看谱与进度

钢琴上方提前生成完整简谱，1=C、4/4 拍。亮框是当前音，虚线框是下一音；数字下方标注音名和电脑键位。可以横向滚动看后续小节，点击音符跳到对应位置；手动滚动后，点「恢复跟随」重新跟随播放。

进度条、百分比、小节 / 拍位及音符序号使用同一音频时钟，暂停或等待时一起冻结。百分比包含预备和尾段；音符序号表示曲谱中的当前位置，与手动按对次数分开显示。延长横线、附点和短音下划线用于显示简化记谱时值。

分段与速度

速度范围 50%–120%，改变速度不改变音高。循环用从 0 开始的拍数，区间为 [A, B)，可输入任意四分之一拍；“定位”选中当前起点后的四拍。时间轴点击可跳转，开启循环时跳到区间以外会回到 A。

实现与曲目数据说明

三角轮廓与 88 键

琴身在水平面以 Three.js Shape 的贝塞尔曲线描边，再用 ExtrudeGeometry 形成厚度；曲线形成左侧直边、后部弧线与收窄的尾端。顶盖始终闭合。琴体、琴腿、踏板及一张琴凳采用低模几何体；不加载外部模型。

从 MIDI 21（A0）遍历至 108（C8），按十二平均律判定白键 / 黑键。52 个白键等距排布；36 个黑键位于相邻白键边界，E/F、B/C 之间不放黑键。两组 InstancedMesh 共享圆角几何体，以实例矩阵与颜色完成下沉、高亮与错音反馈。

两首练习的来源

「小星星」使用公版法国传统旋律，手工写成 C 大调单声部教学数组，未导入外部 MIDI 或现成编曲。完整六乐句共 42 个音符，12 个 4/4 小节，96 BPM；MIDI 60–69。

「欢乐颂」使用贝多芬《第九交响曲》的公版主题，手工简化为前 8 小节的 C 大调单旋律，保留附点节奏，不包含原作伴奏。30 个音符，100 BPM；MIDI 60–67。两曲只用白键，默认音区覆盖全部目标，无需换八度；均含 2 拍预备与尾部留白。数组格式为 [midi, startBeat, durationBeats, velocity]，velocity 为 0–1。

音频时钟、下落条与等待

唯一的播放时间基准是 AudioContext.currentTime。当前位置 = 锚点拍数 +（音频当前时间 − 锚点时间）× BPM × 速度 / 60；RAF 只查询当前位置，反查音符、条位置与琴键状态。自动音频使用 90 毫秒短预调度，暂停、变速、跳转会取消旧调度。静音仅改变主增益。

等待模式每次检查下一组起点；即使帧跳过起点，也将位置精确钳制到该拍，不提前播放目标。用一组已命中 MIDI 音高记录和弦，当目标全部命中才重新锚定时钟。长按旧键不会自动满足下一个音，需松开再按。

手动演奏在自动模式下拥有优先权：首次按键保存当前拍，停止自动声部；所有手动来源（键盘 / 指针）松开后，用同一音频时钟等待 320 毫秒再恢复。主动暂停、换曲、跳转等会取消过期调度。程序合成低音含更多谐波且衰减更长，高音减少谐波；最多 32 声部。

性能与验证范围

无后处理、无粒子、无音频文件或 CDN 请求。移动端限制像素比与阴影精度；FPS 为实际帧间隔的滚动统计，独立于播放时钟。附带的 README 记录本次测试环境、结果和未验证项目。帧率取决于设备 GPU 与浏览器，不能保证所有设备达到 50 FPS。
