# LARGO · 看键跟弹

一个单文件 Three.js 三角钢琴教学演示。完整乐谱预览会在演奏前显示，播放时同步标出当前音符与全曲进度；琴键会跟随旋律高亮并下沉，适合现场展示和初学者跟弹。

## 使用方式

直接打开 `index.html`。页面尝试自动播放；若浏览器阻止自动播放，点击底部播放按钮即可开始并启用声音。可以切换《小星星》和《欢乐颂》，拖动进度、调整速度、开启等待跟弹或设置分段循环。鼠标点击琴键，或使用页面列出的电脑键位，都可以手动试弹。

页面使用程序化 WebAudio 合成音色，不加载外部音频或 MIDI。Three.js 与 OrbitControls 已打包进单个 HTML 文件，运行时无需联网下载依赖。

## 实现与验证

- 88 个琴键由 InstancedMesh 按半音位置生成，白键与黑键分开布局，并遵循钢琴黑键分组。
- 琴身轮廓用贝塞尔曲线构建二维形状，再挤出厚度形成侧面；顶盖保持闭合。
- 两首曲目是根据熟悉旋律自行编写的简化练习数组，采用 C 大调单声部音符，不嵌入版权录音或完整 MIDI。
- 乐谱提前显示所有小节、音级、音名、键位和时值。音符高亮、落键提示与底部进度均由 AudioContext 播放位置推导；等待模式在目标音符到达时暂停，弹对后继续。
- 自动播放与手动输入冲突时，手动操作优先，停止输入后延迟恢复自动演示。

验证记录：项目单元测试 28/28 通过；乐谱与响应式浏览器检查 77/77 通过；针对 1920×1080、DPR 1、RTX 4060 的 Chromium 测量约 60 FPS。没有在其他显卡、移动设备或所有浏览器上验证帧率和音频行为。

## 主生成提示（原文）

做一个单文件 HTML 的 3D 三角钢琴教学场景（Three.js），目标是“看键跟弹”。

【场景与视角】
88 键三角钢琴置于简单室内。相机可 OrbitControls 旋转/缩放，提供“键盘视角 / 侧视 / 俯视”三个预设按钮。默认略微俯视键盘，确保当前该按的键清晰可见。琴身侧面用贝塞尔曲线描边挤出，保留三角轮廓；顶盖固定闭合；内部铸铁板/琴弦可低模暗示或省略。装饰物 ≤2 件，不遮挡键盘。

【键盘】
88 键：52 白 36 黑。黑键真实分组（E/F、B/C 之间无黑键），白键前缘圆角，键缝有深色阴影。白键微黄哑光，黑键乌木哑光。88 键用 InstancedMesh 或等价方案。

【教学引导】
音符以“下落条”形式从上方沿琴键方向落下，落点对准目标琴键；同时目标琴键高亮/脉动，显示“按哪个键、按多久”。
支持 50%–120% 变速和分段循环。
等待模式：播放到目标音符时冻结时间，直到用户按对才继续。
手动输入：白键 A S D F G H J K，黑键 W E T Y U，覆盖 ≥2 个八度；鼠标点击琴键也发声。
按对琴键下沉并发声；按错轻微红色闪烁，不阻断。
自动播放与手动冲突策略：手动优先，自动暂停；松开后短延迟恢复。

【曲目数据（内置数组，禁止外链 MIDI/音频）】
曲目一：野蜂飞舞练习片段（半音阶跑动，约 60–120 个音符，MIDI 21–108，含 start/duration/velocity）。
曲目二：周杰伦风格流行旋律练习片段（8–12 小节简化旋律，可含 ≤3 键同帧），自行编写数组，不嵌入完整版权 MIDI。
两首曲目均以 [midi, startBeat, durationBeats, velocity] 格式写在代码里。

【音频】
WebAudio 程序化合成，不加载任何音频文件。低音区加谐波和较长衰减，高音区减少谐波。首次交互后 resume AudioContext，界面提示“点击开始”。提供静音开关；静音时下落条和高亮仍然可见。
唯一时间基准为 AudioContext.currentTime，禁止 RAF 累加时间。每一帧由播放位置反查音符状态和琴键高亮。

【性能与交付】
1080p ≥50fps，带 FPS 计数器。移动端减少粒子/关闭后处理（如有）。
单文件 HTML。附说明：三角轮廓如何挤出、88 键如何布局、两首曲目的数据来源与简化方式、下落音符与音频时钟如何同步、等待模式判定逻辑、手动/自动冲突策略。如实说明验证了哪些、未验证哪些。
