# 三阶魔方实验室 · CUBE / LAB

纯 CSS 3D Transform 打造的可交互三阶魔方实验室：27 个独立立方块、54 张圆角彩色贴纸，支持拖拽旋转视角、点击色块与键盘转层、20 步随机打乱与一键瞬时复原。单文件、零图片、零外部资源，打开即玩。

[在线预览](https://fanhuayishiy.github.io/ai-demo/rubiks-cube-lab/index.html)

## 功能亮点

- **实体质感**：黑底块体 + 缝隙 + 倒角高光 + 圆角贴纸光泽，明暗随三维朝向动态变化，地面软阴影随光源方向偏移
- **正确转层**：整数坐标 + 3×3 整数朝向矩阵驱动，白 U / 黄 D / 绿 F / 蓝 B / 橙 L / 红 R 标准配色
- **无撕裂动画**：转层 90° 用同构 rotate3d + matrix3d 关键帧，9 块沿同一轴走同心圆弧，终帧零跳变
- **多维交互**：鼠标/触屏拖拽视角（6px 阈值锁定防慢拖误触）、点击色块转其所在面、六面按钮、方向键 + Shift 反向
- **实验室控制台**：复原状态徽章、转动步数、打乱/复原主按钮、最近转动历史

## 技术栈

原生 HTML / CSS / JavaScript 单文件；动画使用 Web Animations API；布局自适应使用 ResizeObserver + CSS 自定义属性。无任何图片、字体、CDN 或外部依赖。

## 关键实现

### 数学系 ↔ CSS 系换轴

数学坐标系 y 上、CSS 屏幕系 y 下：位置渲染时 y 取反，朝向矩阵经 `D·M·D`（`D = diag(1,-1,1)`）共轭后按列主序输出 `matrix3d`；绕 y 的旋转角不变，绕 x/z 的旋转角取反。

### 同构关键帧（圆弧无撕裂的来源）

对 matrix3d→matrix3d 直接做 CSS 过渡会走矩阵分解插值，位移线性化导致方块直线穿越内部。本项目的起止两帧写成完全同构的 `rotate3d(轴,θ) translate3d(P) matrix3d(M)` 序列，浏览器逐函数插值，rotate3d 角度线性展开；终帧 `R·T·M` 恒等于烘焙态 `T'·M'`，动画结束零跳变。

### 动态明暗

每张面片缓存世界法线，拖拽视角时在 rAF 中按视空间固定光源重算明暗（CSS 自定义属性写入伪元素透明度）；转层动画期间对移动层按 Rodrigues 公式随旋转角实时更新。

### 防误触

按下点累计位移 ≤ 6px 视为点击（可触发转层），一旦超过立即锁定为视角拖拽，慢拖不会误转层。
