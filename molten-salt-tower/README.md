# 熔盐塔式发电站可视化

用四个分区、共 124 面定日镜演示塔式光热发电。调整太阳方位角和高度角，可以观察各镜面的跟踪姿态，以及选中镜面把光反射到塔顶吸热器的过程。 [在线体验](https://fanhuayishiy.github.io/ai-demo/molten-salt-tower/)

## 功能亮点

- 按 `1`–`5` 或点击右上角按钮，在上帝视角、第一视角、单镜视角、单机视角和机内视角之间切换。前三层支持拖动旋转、右键或 `Shift` 拖动平移、滚轮缩放和复位。
- 点击镜面或设备，查看反射率、跟踪角、电机电流和功率。后两层用二维设备示意图查看同一台设备的外壳和机内结构。
- 支持温度、负载、电流和数据流四种模式。面板显示分区统计、运行告警、供配电和趋势图。
- 可手动调节太阳角度，也可启动约 30 秒一轮的自动轨迹。选中镜面后，金色虚线表示从太阳到镜面的入射光，青色线表示从镜面到吸热器的反射光。

## 技术与运行

页面采用原生 HTML、CSS 和 JavaScript。电站场景由 CSS 3D 变换构建，太阳、光路、数据流和图表由 Canvas 绘制。固定 1920×1080 的画布随窗口等比缩放。下载并打开项目的 `index.html` 即可离线体验。

| 文件 | 用途 |
| --- | --- |
| [`index.html`](./index.html) | 独立运行页面，包含全部场景和交互 |
| `README.md` | 项目说明和生成提示原文 |

## 验证与边界

Chrome 和 Edge 已验证镜场计数、自由相机、设备点选，以及手动和自动调节时的光路与镜面朝向。太阳采用场景内的有限距离模拟光源，镜面法线取指向太阳与吸热器两条方向的角平分线。运行指标和设备读数均为演示数据。

## 主生成提示（原文）

```text
页面形式
做一个单文件HTML熔盐塔式发电站可视化页面，画布固定1920X1080，深色科技风(底色#04080f，主光青色#22d3ee)。

不引入Three.js，不加载任何3D模型文件，用CSS 3D的transform搭场景。

二、场景内容
一个熔盐塔式光热发电站：中央一座吸热塔（塔顶有吸热器，塔身有熔盐管道），塔周围布置【若干面定日镜】组成镜场，镜场按环形或扇形分区，每面镜子朝塔倾斜；地面画镜场通道线和分区线；旁边配【冷盐罐、热盐罐各一座】、蒸汽发生器房、配电柜；远处墙面有门。顶部有桥架和灯带。

三、五层视角(重点)
场景外层放一个容器当"相机"，切视角只改这个容器的transform，里面的塔、罐、镜面一个都不要动。
要五层，一层比一层近，每层回答一个追问:
1上帝视角

俯视全场镜场、吸热塔、储罐，看整体势态;
2第一视角

镜头压到人眼高度，站在镜场通道里朝吸热塔方向往深处看;
3单镜视角

选中一面定日镜放大，看到镜面结构、跟踪支架、驱动电机、控制箱，镜面边缘拉线缆进竖直理线区再上桥架，左边配镜场编号刻度尺;
4单机视角
点单台设备（跟踪器/驱动电机/控制箱），出设备面板：电机参数、编码器读数、限位状态、状态灯、温度功率;

掀开外壳看机内：双电机驱动、减速机构、编码器、限位开关、接线端子、控制板，进风出风温度;
5机内视角
只做前3层的3D放大。后两层不要放大3D场景，镜场设备标签放大九倍还是糊，改成2D高精面板叠在上面、3D场景退成暗背景，清晰度优先。
切换要有1秒左右缓动飞行，不要硬切。右上角显示视角名，配五个按钮，键盘1-5也能切。

四、四种数据模式
顶部分四个按钮：温度/负载/电流/数据流。切换时改变定日镜镜面和吸热塔顶面的颜色和图例：
温度用五档色阶(正常青、凉绿、偏热黄、注意橙、超过565°C红)；
负载用百分比分档；电流显示单镜安培数；数据流模式不看颜色，改成地面上有光点在流动（沿镜场通道和熔盐管道方向流动）。

五、布局
顶部标题栏+7个KPI指标条；左列放分区温度和实时告警；右列放选中设备的详情和供配电；中间是3D视口；底部三张图：吸热器出口温度趋势、总电流、各镜场分区负载柱状。

六、交互
点任意定日镜或设备，右侧详情跟着变(镜面反射率、跟踪精度、电机电流、功率、运行状态)。
在单镜里点某台设备，直接再进一层到单机；再往下到机内，全程跟着同一台设备走。
选中的镜子和设备都要有高亮边框。

七、硬要求
1数字必须自洽：标题说24面定日镜，下面分档相加就必须是24，不能出现25或23。
2单面定日镜用5个面就够：镜面正面、背面、左右侧面、底面。背面永远背对相机，不要画。
3镜面间距必须大于镜面深度，否则相邻镜子会穿模，屏幕上就是一堆交叠色块。
4上帝视角的动效要画在屏幕空间：光柱、雷达、数据流弧线一律用canvas叠在最上层，不要画进3D场景里，否则一定被塔和镜场遮挡。
5页面里所有数据都是演示示意，不许出现真实企业名和真实地址。
八、太阳角度与定日镜动态跟踪展示

太阳位置驱动
场景中增加一个可调的“太阳方位”控制：用一个滑杆或自动循环模式，模拟太阳从东到西（方位角 60°→300°）、从低到高再到低（高度角 5°→75°→5°）的运动轨迹。太阳位置变化时，定日镜的镜面朝向实时跟随调整，始终保持将阳光反射到吸热塔顶部的吸热器上。

镜面朝向计算与视觉反馈
每面定日镜根据当前太阳方位角和高度角，计算其水平旋转角和俯仰角（用简化几何：镜面法线平分太阳方向与塔顶方向）。CSS 3D 中通过 transform 的 rotateY（水平旋转）和 rotateX（俯仰）实时更新每面镜子的朝向，切换时用 0.2s 左右的过渡让转动看起来自然。镜面正面根据入射角显示不同亮度的青色反光（正对太阳时最亮，偏斜时变暗），塔顶吸热器在接收到反射光时高亮闪烁。

与数据模式的联动
在“数据流”模式下，太阳移动时地面和镜场通道上的流动光点方向随之改变，模拟光线从镜面反射到塔顶的路径；在“温度”模式下，镜面反光强度影响吸热塔顶面颜色深浅（反射越集中，塔顶温度色阶越向红端偏移）。切换数据模式或太阳位置时，所有联动在 1 秒内缓动完成，不硬切。

上帝视角的屏幕空间动效
太阳轨迹线、从镜面到塔顶的反射光束（用半透明青色线段或粒子弧线表示）一律用 canvas 叠在最上层绘制，随太阳角度实时重绘，不画进 3D 场景，避免被塔身和镜场遮挡。太阳本身用一个带光晕的圆形光斑在 canvas 上层表示，位置随角度变化。

交互控制
在顶部或视口角落增加一个“太阳角度”控制条：可手动拖动滑杆调整方位角和高度角，也可一键开启“自动轨迹”让太阳按预设路径循环运动（约 30 秒一个周期）。自动轨迹运行时，右上角视角名旁显示当前太阳方位角和高度角读数。选中任意定日镜时，右侧详情中增加“当前跟踪角”“目标角偏差”两项实时数据。
```
