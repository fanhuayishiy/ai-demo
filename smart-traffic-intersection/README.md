# 路序 LU XU · 智能交通数字孪生

基于 Three.js 的浏览器本地交通仿真，包含可旋转缩放的微缩城市、信号控制、车流自适应配时和行人优先过街。所有车辆、感知数据和统计均由本地仿真产生。

在线预览：https://fanhuayishiy.github.io/ai-demo/smart-traffic-intersection/dist/

## 运行

```powershell
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/ 。依赖已安装时直接执行 `npm run dev`。

```powershell
npm test             # 信号逻辑与交通约束测试
npm run build        # 生成 dist 静态网页
npm run preview      # 查看生产构建，端口 4173
npm run test:browser # 浏览器交互验证，需要本机 Chrome，且开发服务正在运行
```

## 交互

- 鼠标左键拖动旋转、右键平移、滚轮缩放；工具栏提供默认视角、俯视、感知层、标签和全屏。
- 来车强度滑块控制每个方向的车辆生成频率；「南北来车」「东西来车」各添加 6 辆车。手动修改后自动场景脚本暂停，自适应信号控制继续运行。
- 先选择北、东、南、西侧斑马线；「申请过街」提交该处请求，旁边的行人图标模拟行人走向该等待区并自动检测。四条斑马线分别展示信号，同方向的两条线联动放行。
- 底部支持暂停/继续、1/2/4 倍速和自动演示。自动脚本以 100 秒为周期，演示南北高峰、行人优先、东西高峰、第二次行人检测和均衡通行。
- 「查看全部」打开带时间戳、感知原因和决策结果的日志。
- 重置恢复车辆、配时、演示和数据统计。页面切到后台时暂停仿真，回到页面后继续；倍速同时作用于车辆运动和信号倒计时。

## 信号与安全约束

配时按实时来车数量计算：

`绿灯秒数 = round(clamp(12 + 本向车数 × 0.65 + (本向车数 - 对向车数) × 0.85, 9, 32))`

机动车相位与行人相位分别计时，通过过街方向的冲突关系联动：

| 机动车绿灯 | 同时通行的车辆 | 可开放的行人斑马线 | 保持红灯 |
| --- | --- | --- | --- |
| 南北方向 | 北→南、南→北两个直行车道 | 东侧、西侧（南北向过街） | 东西车辆、北侧/南侧人行灯 |
| 东西方向 | 东→西、西→东两个直行车道 | 北侧、南侧（东西向过街） | 南北车辆、东侧/西侧人行灯 |

当前绿灯每 1.5 秒重新评估，最后 3 秒锁定，不因新请求重新跳秒。检测到行人后，若与当前车流平行且能安排完整过街窗口，可直接开放对应人行线；若有冲突，保留 7 秒最短绿灯，提前结束当前绿灯，经 3 秒黄灯和至少 1.5 秒全红清空后，放行新的机动车方向及其平行人行线。全红仅用于机动车换向，不作为每次行人请求的固定阶段。

人行绿灯 11 秒，清空至少 2 秒。较晚到达、无法在本次绿灯内完成过街的行人留待下一次放行。清空期间人行灯闪烁，禁止新行人进入，平行直行车流继续通行，冲突车流持续红灯；若仍有人在斑马线上，显示「清空中」并延续保护。不同方向的过街请求按先后顺序处理，每轮机动车绿灯最多安排一轮人行开放，避免连续请求让另一车流长期无法通行。

场景与信号面板共用同一机动车倒计时，人行信号使用独立倒计时。机动车换向前检查车辆完整车身是否离开路口及出路口斑马线；红灯停车位置包含车长余量，车头不越过停车线。

车辆沿四条独立直行车道运行，使用前车间距限制、加减速和停车线约束。此演示未实现转弯、真实摄像头视频识别、路侧硬件连接或现实交通控制器协议。

平均等待时间为最近 100 辆已通行车辆的累计低速排队时间均值；交通脉搏显示最近 60 个仿真秒的上游车辆数；顶部感知数量显示场景道路范围内车辆。

## 文件

- `src/geometry.js`：共用车道坐标、停车线位置、车辆/行人轨迹和四条斑马线冲突关系。
- `src/simulation.js`：确定性仿真、车流、行人、状态机、统计。
- `src/scene.js`：城市几何体、车辆、行人、信号灯、传感器可视化与相机。
- `src/main.js`：界面联动、用户操作和动画循环。
- `src/style.css`：桌面与手机界面。
- `tests/simulation.test.js`：核心逻辑自动化测试。
- `tests/conflicts.test.js`：并行放行、交叉请求、车身/行人碰撞与连续请求压力测试。
- `tests/browser.cjs`：实际浏览器操作、状态断言及截图。
- `tests/conflicts-browser.cjs`：逐条斑马线验证车辆运动、人行灯、过街高亮和手机操作布局。
- `tests/countdown-browser.cjs`：逐帧倒计时同步与暂停/倍速验证。
- `artifacts/`：浏览器验证报告及桌面、行人过街、手机截图。

技术栈为 JavaScript ES Modules、Three.js、Vite。数据无需后端，字体加载失败时回退到系统字体。

## 静态发布

`npm run build` 生成可直接发布的 `dist/`，资源路径使用相对地址，支持部署在 GitHub Pages 项目子目录。合集收录路径为 `smart-traffic-intersection/dist/`。源码、锁定依赖和自动化测试一并保留；`node_modules/` 与测试截图输出不提交。

## 主生成提示（原文）

请用 Three.js 创建一个可交互的 3D 智能交通路口演示网页，场景包含道路、斑马线、红绿灯、行驶与排队车辆、行人和摄像头/雷达感知可视化，并实现两类核心逻辑：一是根据实时车流自动调整信号配时（车多的方向延长绿灯、车少的方向缩短绿灯），二是当检测到行人站在路口或按下过街按钮后提前切换信号并开放斑马线，同时用倒计时、状态标签和数据面板直观展示感知、决策与红绿灯变化过程，支持鼠标旋转缩放和自动演示。
