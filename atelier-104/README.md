# ATELIER 104

原创全尺寸机械键盘工作台，使用 Three.js 与 Vite，所有配置与方案保存在浏览器本地，无后端服务。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。生产构建使用 `npm run build`，静态产物位于 `dist/`，应通过 HTTP 服务访问。

## 功能

- 104 个独立物理键位的原创程序化模型，拖动旋转、滚轮缩放、透视与俯视切换。
- 四套键帽主题、外壳颜色、铝与 ABS 材质、自定义主键/功能键/点缀键颜色。
- 键帽、轴体、定位板、PCB、底壳五层拆解，支持连续距离调节。
- 鼠标点击或实际键盘输入的按压动画，三种合成按键音，可关闭。
- 底部常亮/呼吸氛围灯。静止时停止绘制，隐藏页面时停止绘制，尊重减少动态效果设置。
- 自动恢复上次配置，最多 20 份本地方案，支持 JSON 导出与导入。
- 独立的实际键盘检测页：`KeyboardEvent.code` 区分左右修饰键、主 Enter 与小键盘 Enter；显示已测键位、同时按下、最大同时按下、有效按下次数与事件记录，支持 JSON 导出。
- 进入页面即自动进行实际键盘检测，已测键帽呈绿色，按住呈金色。预览与详细检测页共用记录，保留重置功能，重置后继续自动检测。输入框、选择控件和弹窗中的键盘操作不会计入检测，移开焦点后自动继续。

## 检测边界

进入设计工作台或详细检测页即自动记录检测数据；鼠标点击不计入实际键盘检测。长按重复事件不增加有效按下次数，窗口失焦会清除按住状态。Tab 保持正常焦点导航。

Fn、Win、Print Screen 与部分快捷键可能由设备、操作系统或浏览器接管，网页无法保证收到全部事件；未收到事件不能直接判定硬件损坏。本工具不检测 USB 扫描率或电气故障。按键音为合成效果。

方案存储仅属于当前浏览器和站点来源，清理站点数据后会丢失，建议导出 JSON 备份。页面仅通过 Google Fonts 获取可选字体，字体不可达时会使用系统字体。

## 验证

```sh
npm test
npm run build
```

`tests/browser_check.py` 需要 Python Playwright 与 Chromium，以及运行在 `http://127.0.0.1:5173/` 的预览服务：

```sh
python tests/browser_check.py
```

浏览器检查覆盖渲染、配色、拆解、保存恢复/导出、按键事件、多键同时按下、长按去重、失焦恢复、自动检测与重置、输入隔离及移动布局。浏览器自动化生成键盘事件用于验证应用行为，不能替代对每一台实体键盘的人工测试。

## 目录与静态预览

- `src/`：网页、104 键布局与 Three.js 程序化模型。
- `tests/`：布局与配置校验、浏览器交互检查。
- `dist/`：随仓库提交的可运行静态产物，使用相对资源路径。

[在线预览](https://fanhuayishiy.github.io/ai-demo/atelier-104/dist/)

在合集根目录运行 `python -m http.server 8000`，打开 `http://localhost:8000/atelier-104/dist/` 即可体验已构建版本。浏览器需要支持 WebGL；字体不可达时使用系统字体。
