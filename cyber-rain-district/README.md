# 雨港 · 霓虹夜 / Neon After Hours

三维赛博雨夜街区氛围图。原生 WebGL 2 绘制霓虹招牌、斜雨、薄雾、湿路面与玻璃倒影；街区几何、贴图和可见字形均在单个 HTML 中程序化生成。

## 运行

双击 `index.html` 即可离线打开，使用支持 WebGL 2 且启用硬件加速的现代浏览器。无需安装依赖、启动服务器或下载素材。

- 鼠标移动：轻微镜头视差。
- 空格 / 暂停按钮：暂停或继续动画。
- F / 全屏按钮：切换全屏。
- H：显示或隐藏界面。
- 保存按钮：导出当前场景的 PNG，不包含界面文字与控制按钮。

## 实现与验证

- 原生 WebGL 2，单文件；没有 Three.js、CDN、外部模型、图片、字体或音频。
- 平面反射、积水与粗糙湿地分区、雨滴涟漪、对街招牌在玻璃中的反射、距离雾、泛光与边缘平滑。
- 撑伞行人、斜面雨棚、消防梯、管线、店铺、售货机与远景楼群均由代码生成。
- 动画最高 60 帧；暂停与后台状态停止连续动画调度，限制渲染像素预算，并支持分配失败时降低分辨率重试。
- 已在隔离 Chrome 离线进程检查宽屏、高像素密度窄屏、暂停、减少动态效果模式、暂停时缩放和 PNG 导出；未发现脚本或 WebGL 报错，独立页面没有外部资源请求。不同设备的性能仍取决于 GPU 与浏览器。

本目录只有 `index.html` 和说明文档；源码 HTML 与本次交付的独立文件保持字节一致。合集的发布脚本会在 `_site` 副本添加统一源码入口、分享和访问统计层，详见[仓库维护文档](../docs/maintaining.md#预览页统一-github-入口与自动发布)。
