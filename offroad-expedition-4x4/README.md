# 荒野行者 · 复古四驱探险车

可从各个角度检查的 3D 越野车，含车身风化、探险装备、活动车门与底盘视角。

## 功能亮点

- 按米建模，轴距 2.49 米，车长约 4.41 米，含顶篷载荷高约 2.22 米。原点在底盘下方中心，Y 轴向上，+Z 指向车头。
- 车门、机盖、翼子板、窗框、透明玻璃、密封条及后置备胎各自拥有独立结构。
- 四轮采用分块人字胎纹和带螺栓的钢轮毂。可见大梁、车桥、差速器、悬架、传动轴、护板、排气和拖车钩。
- 包含防撞架、真实绞盘和缆绳、涉水喉、侧挂油桶、车顶行李架、帆布行李及固定绑带。
- 车漆具有空间连续的褪色、锈蚀、露底、掉漆、划痕和泥痕。橡胶、金属、帆布和玻璃有独立表面细节。
- 页面提供前侧、侧面、后侧和底盘观察视角，可旋转缩放，独立开合驾驶门和尾门，并切换照明。

## 技术栈

原生 JavaScript 和 Three.js 0.180.0，WebGL 2，程序化几何、纹理、自然光照、阴影与基于屏幕像素的程序化材质。Three.js 与所需附加模块、许可证均随项目提供，无需联网下载运行依赖。

## 运行方式

在此项目目录运行 Python 内置静态文件服务：

    python -m http.server 8000

在浏览器打开 http://127.0.0.1:8000/ 。浏览器须启用 WebGL 2。

在合集根目录也可直接打开共享预览，运行 npm run dev 后访问 http://127.0.0.1:5173/ 。

## 独立复用车辆模型

src/vehicle/index.js 中的 createVehicle() 会生成底部中心位于局部坐标原点的车辆根组，以及 setDoor、setLights 和 update 控制方法。只需要车辆模型的项目，可直接把返回值中的 root 加入自己的 Three.js 场景。地面、环境照明和工作台背景由 src/studio.js 提供，不在车辆模型中。

## 目录结构

- index.html：独立可运行的车辆预览页面。
- src/preview.js、src/studio.js：WebGL 场景、灯光、背景、相机与交互。
- src/vehicle/body.js、cabin.js、fittings.js：车身、座舱、灯具与装配件。
- src/vehicle/wheel.js、underbody.js、equipment.js：车轮、底盘与探险装备。
- src/vehicle/weathering.js、materials.js：程序化表面、漆面、泥锈与磨损。
- vendor/three/：Three.js 运行时与使用的附加模块，及 Three.js 许可证。
