> 单位：米。X 向东为正，Z 向南为正（默认机位从南侧看向北），Y 向上。

## 0.5 红线取景（CROP）— 当前生效的可见范围

只保留用户红线框出的那一片，其余全部切掉。常量在 `src/world/plan.js`：

| 项 | 值 |
| --- | --- |
| `CROP` | x ∈ [−17.0, 8.0]，z ∈ [−17.6, 12.0]（两条道路各留约 2/3，路口仍读得出是路口）|
| `PLATE_RECT` | CROP 外扩 0.9 m（草皮边带）= 底座实际尺寸 |
| 底座中心 | (−4.5, −2.8)，**不再是原点**；`origin (0,0)` 仍是全场景坐标原点 |

越界收口分三道，缺一道就会留下「悬在天空里的杂物」：

| 道 | 覆盖对象 | 实现 |
| --- | --- | --- |
| 1 铺面 | `surface / slab / wallX / wallZ` 生成的所有地块 | `kit.clipRect()` 直接截断几何 |
| 2 长条跑位 | 侧沟・レール・標線・路缘石・等距小件 | `kit.clipRun(axis, from, to, at)` 在源头截区间；`curbRun/repeats` 走 `insideClip` 逐件判定 |
| 3 兜底 | 各模块里直接 `mesh(box(...))` 的自由散件（补修パッチ・窨井盖・碎土…） | 装配末尾 `kit.pruneToClip(map)` 按世界位置摘除 + 收回空组 |

**地面标高是查出来的，不是猜的**：`surface()` 是所有地图铺面的唯一出口，它顺手把
`[x0,x1,z0,z1,y]` 记进登记表，`kit.groundYAt(x,z)` 返回该点最高天面。任何要「躺在地面上」
的东西（落樱堆积、空中花瓣的地板、散落杂物）都必须问它 —— 広場 0.009 / 駐輪場 0.016 /
歩道 0.15 / ホーム 0.72 段位差很大，自己写 y 一定不是埋进沥青就是悬在半空。
`motion/petal-storm.js` 的撒花区还额外与 `clipRect` 求交，权重按剩余面积缩放。

**台座是一块实心板，所以资产不允许「切一半」**：`placeAll()` 建完每个资产实例后量真实包围盒，
只要越出 `CROP` 超过 6 cm 就整件不落地（记入 `engine.overflow`）。因此以下落位被改过：
