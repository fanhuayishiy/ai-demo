# H₂ NEXUS · 综合能源数字孪生

一个可本地运行的含氢综合能源园区演示。三维模型全部程序化生成，Three.js、字体及界面已打包到 `assets/`，无运行时 CDN 或远程模型依赖。

> 在线演示：<https://fanhuayishiy.github.io/ai-demo/hydrogen-energy-system/>（Pages 已公开部署，持有链接即可访问）

## 主生成提示（原文）

> 制作一个高科技风格的 3D 含氢综合能源系统动态可视化网页：支持 360° 旋转观察，包括能源流动的各个环节，各个设备合理布局，点击各能源设备可查看实时运行参数；
> 包含的能量流有：电-热-冷-氢，天然气。要先考虑好能量转换关系，在什么设备中可以完成对应的能量转换。
> 管线具备能量流动动态粒子效果，配备可调节气象与负荷的实时数据控制面板；重点保证清晰的工业建模、发光流线动效、真实能量守恒逻辑、深色科技质感

## 运行

在仓库根目录启动静态服务器：

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123/hydrogen-energy-system/
```

开发使用 Node.js 24：

```bash
cd hydrogen-energy-system
npm ci
npm run dev
# http://localhost:5173
```

验证与构建：

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

`assets/app.js`、`assets/app.css` 及本地字体文件为生成的静态发布产物。更改源码后运行 build 更新，不手动编辑生成文件。

## 场景与设备

- 园区含光伏阵列、风力发电机、PEM 电解槽、储氢罐、燃料电池、天然气调压站、燃气热电联产、空气源热泵、复合制冷机组与用能建筑；设备外壳、罐体、管路、光伏板、风机叶片、园区底座与工业标识均程序化生成。
- 深蓝金属底色 + 五色能量编码 + 阴影与辉光后处理，配合工业数显字体。

## 交互

- 鼠标拖动 / 单指滑动：360° 环绕；滚轮 / 双指手势：缩放；右键拖动：平移。工具栏另有自动环绕、俯视视角与视角复位。
- 设备标签、模型点选与侧栏下拉框均可选择设备；设备参数每秒刷新。
- 底部五色图层按钮切换能流类型。粒子方向遵循能流方向，零功率时停止；电网连线按进出口方向反转。
- 右侧调节辐照度、风速、温度、电 / 热 / 冷负荷；晴朗、多云、夜间可快速切换。
- 暂停同时冻结库存积分、趋势和管线粒子；暂停时可重新计算新参数下的稳态功率，库存不变化。
- 1× / 10× / 60× 改变仿真时钟及储氢积分速度。每次实际刷新间隔最多计入 2 秒，后台休眠不补算。
- 重置气象与负荷保留储氢库存。刷新页面重置本次会话。
- 能量拓扑展示转换链，运行记录可导出 CSV。
- 适配手机；支持键盘操作、减少动态效果偏好、WebGL 不可用时的说明及二维控制后备界面。

## 模型与边界

**本地仿真数据，不是现场遥测。** 功率单位 kW；氢和天然气使用低位热值（LHV）；太阳能、风能以电输出为系统边界。

| 设备 | 转换 / 约束 |
| --- | --- |
| 光伏 | 900 kWp，输出随辐照度变化，温度系数 −0.4%/°C（相对 25°C 的简化环境温度修正） |
| 风电 | 600 kW，3 m/s 切入，12 m/s 额定，25 m/s 切出；区间内立方功率曲线 |
| PEM 电解系统 | 可再生电余量的 90% 优先制氢，最大 450 kW；净 LHV 效率 68%，其余 32% 散热，辅助设备耗电已计入净效率 |
| 高压储氢 | 4,000 kWh，初始 62%；33.33 kWh/kg；积分限制禁止超充或透支 |
| 燃料电池 | 可再生发电不足时投入；最大氢输入 260 kW；电 52%、回收热 32%、散热 16% |
| 燃气热电联产 | 燃气输入限制 1,100 kW；电 36%、回收热 46%、损耗 18% |
| 空气源热泵 | 补足热负荷，COP 随温度变化并限制在 2.1–4.6；单独计入环境吸热 |
| 吸收式制冷 | 在预留部分直供热后利用余热，COP 0.72 |
| 压缩式制冷 | 补足冷负荷，COP 随温度变化并限制在 2.6–5.5 |
| 电网 | 双向进出口平衡母线，不设容量上限 |

电、热、冷基准需求分别为 620 / 560 / 420 kW，负荷滑块范围 0–160%。热泵和压缩式制冷按需求补足，不模拟容量饱和。设备详情中的产能与效率是模型计算值或设计常数；不虚构温度、压力等未经求解的遥测参数。

### 守恒

```text
电：光伏 + 风电 + CHP + 燃料电池 + 电网净输入
  = 用户用电 + 电解 + 热泵用电 + 压缩制冷用电

热：直供热 + 热泵供热 = 用户热负荷
冷：吸收式冷量 + 压缩式冷量 = 用户冷负荷
氢：储量变化 = (产氢功率 - 燃料电池氢输入) × 模拟时间

全站输入：
  可再生电 + 天然气 + 电网购电 + 环境吸热 + 用户侧移热 + 储氢释放
全站输出：
  用户电热负荷 + 冷凝排热 + 设备损耗 + 电网售电 + 储氢充入
```

冷量是从用户侧移走的热量，不是新增能量。冷凝排热包含移走的冷量与制冷驱动能量。热泵输出高于耗电的部分来自环境。热电联产多余热量显式计入排热。

模型是稳态功率分配与动态储氢的组合，不模拟启停、管网压降、气体状态方程、设备劣化、水处理或真实控制器。三维管线是拓扑示意，不是施工配管图。

测试覆盖 135 组气象 / 负荷组合与四种库存状态（共 540 组）、空满罐、风机切出、24 小时连续运行及暂停再计算，检查各载能体和全站守恒。TypeScript 严格检查、ESLint、静态构建与这 5 项模型测试均通过。

## 源码

- `src/simulation.ts`：独立纯函数仿真及边界约束
- `src/scene.ts`：程序化设备、轨道相机、选取、管线及粒子
- `src/devices.ts`：设备语义与运行参数
- `src/main.ts`：控制、趋势、运行记录及详情
- `src/palette.ts`、`src/style.css`：共享视觉 token 与响应式界面
- `tests/simulation.test.ts`：物理不变量测试

Rajdhani 用于工业数显，IBM Plex Mono 用于小型技术标记，中文采用系统字体。配色以深蓝金属质感为背景，五色管线专用于能量类型编码。
