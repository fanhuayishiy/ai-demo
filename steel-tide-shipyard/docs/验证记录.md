## 连续昼夜与近景补充

独立代码复核后补充的 **4 项浏览器回归全部通过**：舷梯撤收时中途观察者返回安全码头；收尾时修改日速保留当前吊装；隐藏构件不可被点选；从海试回看待装分段和舰岛时清除俯仰、横摇。问题均先以实际浏览器复现，再完成修复和回归。详见 `review-regressions.json`。

- 完整日内循环：日速 96×，实际运行 15.23 秒，覆盖全部 24 个小时及准备、施工、收尾、值守四种班次；舰体始终系泊，工程阶段与进度没有随跨日重置。天色采样连续变化，夜间必要点光源启用。详见 `day-cycle-results.json`。
- 甲板方向：舰体朝向反转后，按 W 的世界坐标 Z 从 30.000 增加到 33.001，与镜头前方一致。
- 舷梯通路：沿实际岸舰斜向通路采样，镜头高度依次为 6.100, 9.550, 13.000, 16.450, 19.486 m，随楼梯上升；可以在通路端部进入甲板，甲板避开舰岛占用区域。
- 已目视查看初始合拢、八阶段截图、局部剖视、夜景、舷梯/甲板与窄屏截图。支座、施工面与临时通路是简化几何，未作通用碰撞求解或逐帧全场碰撞验证。

## 性能与运行范围

本机硬件渲染在 1440 × 960、像素比 1 下，预热后六次 1.1 秒间隔采样为 **60, 60, 60, 60, 60, 60 FPS**，已设置约 60 FPS 的绘制上限。合拢视角约 185–187 次绘制、77,884–81,508 个三角形。此结果仅适用于本机短时采样，不是所有设备的性能保证。

另一次 Chromium 156 / SwiftShader 软件渲染检查中约 4–8 FPS；程序会降低软件渲染像素比到 0.75，但软件渲染明显较慢。推荐硬件加速。未测试手机实机 GPU、Safari、Firefox、Edge，也未做数小时运行、显存压力或热稳定性测试。

页面 JavaScript / WebGL 错误：最终自动验收中 **0**。离线验收的 HTTP(S) 请求：**0**。

本地开发脚本以 PORT=5174 启动并返回 HTTP 200，页面与离线 HTML 逐字节一致；测试子进程随后关闭。默认启动端口为 5173。

**离线文件协议入口：通过。资源管理器物理双击：受限，未核验。** 已尝试读取项目的资源管理器窗口，但 Windows 截图助手先后报告 `FrameArrived timed out` 与 `window capture timed out`，按工具恢复规则停止了桌面输入。没有把 `file://` 的自动化验证冒充实际双击，也没有切断用户整台电脑网络。用户可直接在资源管理器中双击最终 HTML 检查默认浏览器关联。
