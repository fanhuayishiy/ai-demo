# 钢潮入海 · 设计与状态约定

## 画面方向

将船厂视为一幅正在运行的工艺路线图：主画面保留空间，八阶段时间轴沿画面底部铺开；主线 B-07 的黄色身份从材料流转中延续到舰体。浅色界面参考工程记录纸，避免遮住关键动作。

色彩：冷灰钢板 `#738994`、氧化红 `#9D5446`、橙黄吊机 `#E5A431`、青蓝港水 `#4B929A`、暖白灯光 `#FFD69A`、深青文字 `#23444B`。标题使用本地宋体系列，界面用系统中文无衬线体，编号用 Bahnschrift / Consolas；不加载外部字体。

## 空间与尺度

单位为米，实体长方体的位置与尺寸量化到 0.2 m 网格。X 横向，Y 竖向，舰首朝向本地 -Z。场地陆面 Y=4，海面 Y=0，坞底约 Y=-14，干坞舰底 Y=-11，起浮后舰底约 Y=-8。

钢材堆场位于加工车间外侧；加工与预制在陆侧并行，预制棚设有适配主线分段的开放侧门。48 m 宽重载道连接预制区与接驳位。两条龙门吊轨道位于 X=-85 与 X=126，交接位、B-07 缺口和舰岛地面支座均处于覆盖范围内。

B-07 的装配基点为舰体局部 `[-10.8,-1,-15]`。在干坞中的世界坐标为 `[49.2,-1,-30]`。板件编号始终为 B-07；安装后同一对象采用舰体的世界变换，随起浮、拖带、转向和海试整体移动。

## B-07 工序节点

| 第四阶段进度 | 当前承载 / 动作 |
| --- | --- |
| 0–10% | 分段在胎架，SPMT 横移进入支墩空隙 |
| 10–18% | 货台抬升 0.8 m，承接分段 |
| 18–39% | 沿重载道横移、纵移和接驳；转向节点减速至停 |
| 39–46% | 货台下降，分段落在接驳支座 |
| 46–57% | 空车退出，司索工经通达平台挂索并撤离 |
| 57–66% | 垂直提升至越过坞壁的净空 |
| 66–79% | 吊机横移至目标缺口上方 |
| 79–90% | 缓慢下放至舰体定位支承 |
| 90–94% | 已承托，吊索仍连接；检查后解钩 |
| 94–100% | 空吊具回升，装配工经脚手架接近接缝 |

分段本体位置和空吊具位置均做连续性采样测试。已经完成的顺播节点不会自动循环，重复观察必须拖动工序进度或显式重播。

## 出坞节点

0–12% 撤收与检查；12–42% 注水，水位由 -13.7 m 升至 0；水位高于 -3 m 后舰体逐渐起浮，竖向位移最大 3 m；42% 后齐平并系固；45–52% 开门；52% 挂拖缆；54–72% 沿坞口轴线出坞；72–86% 在港池回转；86–99% 低速靠泊；99% 后系缆并释放拖缆。

## 可复现状态

工程阶段、阶段进度是几何和承载关系的唯一来源；日内时刻、工程累计时间分别驱动天色和当班动画。暂停不会阻止相机或手动定位。夜间跳时使用明确的安全节点重建物料、吊具、舰体、水位、坞门与缆索，而不是单独切换天空颜色。

海试使用连续曲线的切线控制朝向，速度控制尾流长度与轻微船姿；泊位离开和返回为低速拖带，港外才进入自由航行。尾流根据近期航迹重建，回看阶段时不会遗留上一条航迹。
