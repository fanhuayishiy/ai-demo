# 钢潮入海

一座可游览的三维体素船厂，一艘贯穿设计、建造、下水、舾装和海试的原创常规动力航母。

[在线体验](https://fanhuayishiy.github.io/ai-demo/steel-tide-shipyard/dist/) · [离线单文件](./钢潮入海.html) · [实际验证记录](./docs/验证记录.md)

**直接打开：双击项目根目录的 `钢潮入海.html`。** 三维引擎、代码、样式和程序生成的材质全部内嵌，无须安装、无须联网。建议使用开启硬件加速的 Chrome 或 Edge，浏览器需支持 WebGL 2。

## 游览

- 左键拖动旋转，右键拖动平移，滚轮缩放。数字 `1–6` 切换总览、车间、坞壁、坞口、码头与近海随航。
- 底部八个阶段可以随时跳转；细进度条定位当前工序中的任意瞬间。`工程顺播` 控制工程，`工序重播` 显式重置当前工序。
- `F` 跟随 B-07；`C` 打开局部外板，查看肋骨、管路、电缆托架和设备底座。点击实物查看名称、编号及工序。
- `G` 进入安全步道；`W A S D` / 方向键行走，拖动转向，`Shift` 加速。系泊后点击 `登舰观察` 进入开放的甲板观察点。
- **空格暂停整个世界**：工程、日内时钟和作业动画同时冻结，镜头、界面和手动定位保持可用。
- 右上时钟可任意跳时、关闭自动昼夜循环、调整日速。`H` 或标题旁的 `?` 打开帮助；帮助中可选择“从第一块钢板开始”。

初始位置为白天的第四阶段：B-07 正由平板车运向干船坞。完整顺播约 8 分钟（工速 1×、不含作息等待）；快速查看可用工速 12×，关闭昼夜自动推进并把时刻放在 08:00–17:00。

## 两条独立的时间线

工程使用固定顺序的八阶段和阶段内进度；日内时钟管理光照及班次。日速 1× 是展演速度，约 60 秒相当于日内 1 小时。

| 日内时间 | 船厂行为 |
| --- | --- |
| 06:30–08:00 | 入场、准备与设备待机，不开启重载任务 |
| 08:00–17:00 | 派发当前阶段的工作 |
| 17:00–19:00 | 完成正在执行的工作，不开始下一阶段；人员退场 |
| 19:00–次日 06:30 | 夜间值守，车辆停车、吊具待机，保留安全照明 |

出坞和海试在剩余窗口足够时才启动。日速很高、工速很低时，连续任务可能一直等待：降低日速、提高工速，或关闭自动昼夜推进即可获得足够窗口。工程不会为了追赶时钟跳过吊装或拖带。

手动跳到夜间会选取安全快照：悬吊的 B-07 回到接驳支座，起浮后的舰体可在封闭船坞内系固，已经开始的拖带或海试到达系泊节点。回到工作时间后从该节点继续。历史阶段跳转会重建舰体、车辆、吊具、人员、水位、坞门、拖缆与脚手架。

## 工程与身份

- 虚构舰名：**沧澜舰 CV–08**，约 269 m 舰体，约 64–72 m 飞行甲板宽度；常规动力、平直甲板、约 8° 斜角着舰区、右舷舰岛、两座舷侧升降平台。
- 十六个可辨识主舰体分段，其中 **B-07** 是左舷中部的同一件三维对象。相同编号贯穿排样、板件配套、胎架组立、SPMT 转运和船坞合拢。
- B-07 的承载顺序：胎架 → 转运车 → 接驳支座 → 龙门吊 → 舰体支承。先承接再释放；起吊全程挂索，落稳后解钩，之后装配工才接近。
- 水面从坞底升高，起浮后舰底离开坞墩；水位齐平后开门，挂拖缆出坞，转向后靠泊系缆。海试先低速倒出港池，再转向、加速航行，减速返港。

需要 Node.js 22 或更新版本。仅首次安装开发依赖需要网络；成品 HTML 运行不需要网络。

```powershell
npm ci
npm run dev
```

浏览器打开终端显示的 `http://127.0.0.1:5173`。修改 `src` 后会重新构建，刷新页面查看。

```powershell
npm test
npm run build
```

构建会同时生成 `dist/index.html` 与根目录 `钢潮入海.html`，两者内容完全相同。没有 CDN、外部字体、远程图片、运行时请求或服务端依赖。

## 实现边界

这是原创的工程叙事作品，使用预设路线、关键帧与可重建的状态机，**不是真实航母施工方案或结构、流体力学仿真**。舰体由代表性的十六个主分段表达；部分机械、人员及工序按展演节奏简化。路径按场地净空布置，步行被限制在开放区域，没有通用刚体碰撞或自由寻路求解器。

所有实体按 0.2 m 建模网格生成，多体素长方体实例化合批；标线和缆索用轻量几何表示。远景收起工人手臂及小编号细节，像素比封顶，软件渲染使用较低分辨率，画面更新限制为约 60 FPS。暂停后静止画面停止重复绘制。没有真实企业、现役舰型、生产数据或外部美术素材。

# 《钢潮入海》

## 【创作目标】

在一座临海的大型船厂里，一艘航空母舰从钢板、骨架和舱段逐渐建成。钢板在车间里下料成形，平板转运车载着分段驶向干船坞，龙门吊将它送入舰体的缺口。随着飞行甲板铺设、舰岛就位，船坞开始注水，舰体第一次离开坞墩，随后出坞舾装、海试并交付。

请创造一座可以走近观察、可以沿建造进度游览、可以经历完整昼夜变化的体素船厂。以**同一艘原创的常规动力平甲板航母**贯穿全过程，保持舰体轮廓、分段编号、设备位置和施工进度相互一致。让观众看得懂一块钢板如何成为舰体的一部分，以及船厂为什么要在这个位置、这个阶段进行这项工作。

## 【场景要求】

### 1. 船厂布局与在建航母

将钢材堆场、加工车间、分段预制区、重载转运道、干船坞、舾装码头和出港航道组织成一条连贯的工程路线。陆侧布置钢材和设备进场通道，临水侧安排舰体出坞、拖轮作业和码头靠泊。用车间门洞、转弯区、接驳位、轨道和系缆设施交代各区域如何衔接。

干船坞是构图中心。表现下沉的坞底、沿舰体布置的坞墩、坞壁、坞门和两侧龙门吊轨道。建造中的舰体由坞墩或已安装结构支承，车间里的分段落在胎架或支墩上。道路宽度、车间净空和龙门吊覆盖范围应与可见的构件尺寸匹配。

航母采用外飘的飞行甲板、斜角着舰区、右舷舰岛和舷侧升降平台，形成清楚的轮廓。在早期阶段留出能看见肋骨、纵向加强结构、舱壁和未封闭舱室的视口。将临时脚手架、作业平台和登舰通道接到实际施工面，并随封舱、注水和移泊调整或撤收。

### 2. 用八个工程阶段表现从设计到交付

提供**可跳转、可连续播放的工程时间轴**。按以下顺序组织同一艘舰的可观察变化，允许预制和预舾装在不同作业区并行。

1. **设计与放样。** 在船厂总览上展示半透明的目标舰体和分段划分，指出关键分段的装配位置。在车间显示钢板排样和划线，让观众看到图纸轮廓如何对应待切割的实体。
2. **钢材加工。** 钢材入库、表面清理、吊运上台、切割和成形。用可观察的切缝、板件轮廓和工装展示原料如何变成外板、舱壁和加强构件。加工完成的板件按分段编号配套码放，等待送入分段车间。
3. **分段制造与预舾装。** 板件在胎架上组立，逐步形成带骨架、舱壁和开口的舰体分段。选一处尚未封闭的舱室，展示管路、电缆托架或设备底座在封闭前装入。完成的分段保留吊点、编号和可供转运车进入的支承空间。
4. **干船坞合拢。** 从底部分段就位开始，依次接入舷侧、艏艉和上部结构。选择一个代表性分段完整演示转运、吊装、对位与固定。分段落稳后加入舰体，接缝附近出现定位、检查和焊接作业。
5. **飞行甲板与舰岛安装。** 先让观众看见甲板下的支承结构，再安装甲板分块和外飘部分。用一次重吊展示舰岛从地面支承位升起、移到右舷基座上方并落座。随后补齐升降平台、护栏和可见的甲板设施，保留后续舾装的作业面。
6. **注水下水与拖带移泊。** 展示水线以下的涂装、封闭检查和临时设施撤收，再让坞内水位逐渐升高。舰体达到起浮条件后离开坞墩，坞内外水位齐平后开启坞门。拖轮挂缆、带舰缓慢通过坞口，移至舾装码头并系缆。让观众看清水线、坞墩、舰体和拖缆的相对位置如何变化。
7. **码头舾装与系泊试验。** 在靠泊状态下通过舷梯、岸吊和服务管线组织人员与设备上舰。展示甲板标线、舰岛外部设备和剩余舾装逐项完成，并演示升降平台空载往返、舰上照明分区点亮等可见的功能检查。
8. **海试与交付。** 解缆离泊，在可游览的近海水域演示航行、转向和减速，表现船体姿态、尾流与速度的关系。海试结束后返港靠泊，用完整舰容与交付节点收束工程。工程时间轴可回看任一历史阶段。

各阶段应有对应的实物变化和作业活动。自动播放时，重要工序先完成一次，再进入下一阶段。后续阶段继承前序已完成的结构、物料和停靠位置。手动回看时，舰体、人员、机械、水位和坞门一并恢复到该阶段对应的状态。

### 3. 让运输、吊装与人员协作形成一条可追踪的链

选择一个带醒目编号的舰体分段作为主线。让同一分段编号贯穿放样图、配套板件和分段外壁。分段在车间内组立并移到临时支墩上，模块化平板转运车进入支墩间的空隙，抬起货台承接分段，沿重载通道驶入龙门吊覆盖范围，再把分段落在接驳支座上。通过轮组转向、车辆减速、货台升降和工人指挥表现装载、行驶和卸载。

龙门吊在接驳位放下吊具、挂接分段吊点并垂直提升，达到足够净空后再沿轨道和横梁转运。承重期间保持吊索与吊点相连。分段在目标缺口上方减速，缓慢下放到定位支承处，待落稳后解钩，吊具回升，人员再进入接缝区域进行固定。同一编号、外形与可见特征应从装车延续到合拢后的舰体。

设置可辨识的车间工人、转运指挥员、吊装司索工、装配工和码头系缆人员。每个岗位有对应的工位、出发点和步行路径。指挥员在道路侧方引导车辆，吊装期间人员退至警戒线外，货物落稳后再接近。用走动、手势、短暂停顿和工具动作表现协作，各岗位按工序错开节奏。

可使用预设路线、关键帧和状态机。为每次物料交接明确当前承载者及落点。吊装、合拢和出坞等里程碑在工程顺播中推进一次。需要反复观察时，通过显式的工序重播回到起始状态。

### 4. 独立的工程进度、昼夜循环与船厂作息

**工程时间轴管理舰体建造进度，日内时钟管理光照和当班作业。** 提供连续的 24 小时循环，支持自动推进、任意时刻跳转、暂停与倍速。太阳、月亮、天空、水面高光、环境光和阴影随时间连续变化，码头照明、工作灯和航标灯随天色与班次协调启闭。

可采用以下作息作为默认设置。

- **06:30–08:00 准备。** 工人从门岗、休息区进入工位，车辆出场，设备检查和备料逐步展开。
- **08:00–17:00 施工。** 当前工程阶段对应的加工、转运、吊装或舾装按任务运行。
- **17:00–19:00 收尾。** 停止派发新任务，完成当前货物落位，收起空吊具，车辆驶入停车区，人员沿通道退场。
- **19:00–次日 06:30 值守。** 设备处于停放或待机姿态，舰体停在坞内或系泊位，保留门岗、码头、航标和必要的安全照明。

注水出坞、拖带、海试等连续任务应预留完整作业窗口，在自动收工前抵达可停靠的安全节点。手动跳到夜间时，按当前阶段选择一致的安全快照，使舰体位置、水位、坞门、拖缆、物料和设备状态互相匹配。次日恢复时，从该阶段的下一项待完成任务开工。

暂停同时冻结日内时钟、工程推进和施工作业动画，保留镜头操作、界面操作与手动定位能力。

### 5. 全景与近景游览

提供可旋转、平移和缩放的全景观察，以及从厂门或安全步道出发的地面游览。让观众能走近车间观察窗、分段接驳区、船坞边平台和舾装码头，在已开放的路线进入一处舷梯或甲板观察点。步道随施工状态接通，沿线能看清起吊、落位和拖带的关键动作。

可设置车间、坞壁平台、舰岛吊装位、坞口和码头等快捷视点，并为主线分段提供跟随观察。支持可开合的局部剖视，用于查看外板后方的骨架和预舾装区域。初始画面设在白天的船坞合拢阶段，从斜上方同时看见已成形的舰体、龙门吊、转运通道和一次正在进行的物料交接。

界面保持简洁。以工程阶段条、时间控件、视角切换和可收起的操作帮助为主。选中构件时显示简短的名称、编号及当前工序。

## 【审美与体验】

采用统一的 **0.2 m/voxel** 建模尺度。以冷灰舰体、氧化红底漆、橙黄龙门吊、青蓝港水和暖白作业灯建立清晰的色彩关系。用外飘甲板的阶梯轮廓、分段接缝、脚手架落脚点、吊具和支墩表现尺度与工艺。远景要有舰体、吊机和港湾的层次，近景要看清钢板码放、轮组、吊点、缆桩和工位细节。

让焊花从正在施工的接缝短暂溅出，打磨粉尘在工位局部扬起并消散，注水时水面沿坞壁上升，拖轮转向时留下与航迹一致的短尾流。用晨光掠过坞壁、黄昏映出未完工舰体的剪影、夜间工作灯照亮局部结构，建立一天中不同的观察体验。

使用合并网格、实例化和按距离简化等方式处理大量体素。优先保证舰体结构、物料交接、船坞注水和近景游览的清晰度与运行稳定性。
