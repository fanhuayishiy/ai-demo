# 松风镇

一个可以直接游玩的 Three.js 体素乡村小场景。中文界面，斜俯视正交镜头；全部模型通过程序生成，无图片、字体、音频或模型素材请求。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地网址（默认 http://127.0.0.1:5173）。也可双击 Windows 下的 `启动小镇.cmd`，首次运行会安装依赖。请通过本地服务器访问，不要直接双击 index.html。

## 操作

- WASD / 方向键：移动，方向与屏幕一致。
- E：与附近村民交谈、阅读告示、采摘成熟胡萝卜；再次按 E 收起文字。
- Esc：关闭互动文本。
- 鼠标滚轮：缩放视野。
- 触屏设备：使用左下方向按钮与右侧 E 按钮。

初始位置在中央广场西南侧，邻居杏子就在身旁。向西沿支路可到菜园，向东沿主路过木桥可到树林。三栋小屋只展示外观。18 根胡萝卜采摘后在本次游玩中消失，刷新页面恢复；不包含存档、室内、背包或种植系统。

## 构建和验证

```sh
npm test
npm run build
npm run preview
```

`dist/` 是可部署到普通静态托管的生产文件。开发与构建均使用本地安装的 Three.js，不依赖 CDN。需要支持 WebGL 的现代浏览器。

`tests/core.test.js` 覆盖屏幕方向、匀速移动、房屋/树林/河岸碰撞、木桥通行、防穿透、区域可达性及互动选择。

有 Python Playwright 环境时，可启动开发服务器后运行 `python tests/browser_check.py`，验证真实键盘移动、镜头跟随、三类互动、所有作物采摘、桥与河岸行为，并输出截图和报告到 `test-results/`。

生产版本也可单独检查：运行 `npm run preview -- --port 4173` 后，在另一终端执行 `python tests/production_check.py`，验证打包页面、互动和零外部素材请求。Python 检查需要先安装 Playwright：`pip install playwright`、`python -m playwright install chromium`；日常游玩不需要 Python。

## 文件

- `src/core.js`：碰撞、移动与地图基础数据，不依赖渲染。
- `src/models.js`：程序生成的小屋、树林、花草、农田、河流、桥与体素人物；静态方块按材质合批。
- `src/main.js`：Three.js 场景、跟随镜头、输入、互动与轻动画。
- `src/style.css`：简洁的中文提示与响应式触屏操作。

为可重复的浏览器检查，仅开发模式的 `?test` 页面提供只读 `window.__town` 状态；没有传送或跳过游戏逻辑的接口。

## 主生成提示（原文）

以下保留创建本项目时的用户请求（包含 `/goal` 指令）：

```text
/goal 请帮我制作一个可在浏览器中游玩的 3D 体素小镇，参考《星露谷物语》温暖、悠闲的乡村氛围，使用 Three.js 实现，中文界面。

画面采用方块体素风格、柔和的暖色调和斜俯视正交镜头。小镇包含几栋色彩各异的小屋、一片农田、中央广场、树林，以及带木桥的小河，用小路将这些区域连接起来。加入栅栏、路灯、花丛、木箱等细节，让场景有生活气息，避免只有空旷地面和零散方块。

玩家控制一个简单可爱的方块角色，使用 WASD 或方向键移动，镜头平滑跟随。移动方向与屏幕方向保持一致；房屋、树木和河流具有碰撞，木桥可以正常通行。地图保持小而完整，各区域都能沿道路抵达。

添加少量简单互动：靠近村民按 E 显示一句日常对话，靠近告示牌查看小镇介绍，靠近成熟作物可以采摘并获得文字反馈。可交互对象附近显示清晰的按键提示。

这是一个轻松探索的小场景，首版只做一张地图和以上互动，房屋暂时只做外观。界面仅保留操作提示和互动文本，让画面占据主要空间。加入轻微的树木摇摆、水面动画和角色行走动画。

尽量用程序生成模型，减少外部素材依赖。请交付真正可以操作的完整项目，先确保移动、碰撞、镜头和互动正常，再完善画面，并提供简明的启动方法。
```
