# 浅海 · Ocean Shallows

俯视视角的热带浅海：白沙沙滩、一棵被风吹动的棕榈树、从岸线由浅绿松石渐变到深蓝的海水，以及一群在水下游动的热带鱼。单文件 Three.js 页面，打开即看，可点击水面投下涟漪。

[在线预览](https://fanhuayishiy.github.io/ai-demo/ocean-shallows/index.html)

全部几何与纹理都在运行时程序化生成，没有任何外部模型、贴图或音频文件；唯一的外部依赖是 CDN 上的 Three.js r128。

## 功能亮点

- **海岸线**：不是圆，而是「大圆弧 + 多尺度角向正弦扰动」构成的不规则曲线，`shoreD(q)` 统一给出到岸线的有符号距离（`d > 0` 为海，`d < 0` 为陆），几何、着色、涟漪落点判断共用同一份定义。
- **水深**：`groundH(q)` 是唯一的水深来源，近岸缓坡 + 离岸加速下沉 + 沙坝/礁丘 + 多尺度起伏，噪声振幅随离岸距离渐增，保证近岸不会被顶出水面。
- **水体**：分通道吸收 `exp(-vec3(0.235, 0.056, 0.040) * depthV)`（按清澈潟湖取值，不是外海），加海床透射光与水体散射的物理合成，再叠一条纵深衰减。
- **焦散**：三组不同方向的行波各取「过零点」脊线、取最大值得到三角网，再用两级域扭曲打碎成不规则曲线；只作用于折射贴图，越浅越强，远处按距离淡出。
- **涌浪**：平面波相位与圆弧相位按水深混合，模拟波浪折射；每条波峰加相位抖动破除等间距感，破碎白浪挂在波峰前坡上并按低频噪声分段。
- **鱼**：参数化建模。体形由单调三次样条定义（吻端厚薄、最厚处、尾柄粗细），沿体长逐站生成椭圆截面；背鳍/臀鳍是贴体表的带厚度薄片，尾鳍按轮廓采样扇形三角化并带缺刻，胸鳍可独立扇动，眼睛三层球。7 种鱼共 22 条，用 InstancedMesh 分 5 组绘制。
- **交互**：点击或触摸水面生成涟漪，射线求交到水面平面，只在水域生效；涟漪是解析式行波，随距离与时间双重指数衰减，波前用宽过渡包络平滑收尾。

## 技术栈

- Three.js r128（UMD，CDN 引入）
- 原生 WebGL2 / GLSL ES，全部着色器手写 `ShaderMaterial`
- 无构建步骤、无框架、无 npm 依赖

## 关键实现

### 预烘焙（性能的主要来源）

场景是纯填充率受限的：逐项关闭着色器功能只提升几个百分点，而降分辨率能提升 2.5 倍。所以优化都围绕「减少每像素运算」：

| 烘焙项 | 内容 | 收益 |
| --- | --- | --- |
| 地形贴图 2048² | 岸线距离、水深、海底高度 | 取代每像素的 `atan` + 4 个 `sin` + 3 层噪声 |
| 波场 1024² | 涌浪梯度、波高、波峰斜率 | 水面片元从整串求值降到一次采样 |
| 细节噪声 | 两层低频噪声 | 取代每像素 4 次 `vnoise`（16 次 hash） |
| 叶片阴影 384² | 12 片叶子的 SDF | 该计算原本占整帧 35% |

### 其他要点

- 水面不透明 + `renderOrder = -1` + 写深度，让被水面完全遮住的海床像素被 early-Z 剔除。
- 折射贴图半分辨率（0.66 倍），在清晰度与开销之间取平衡。
- 渲染倍率上限锁 1.0，另有自适应控制器：连续掉帧时自动降低倍率，稳定后缓慢回升。
- 鱼影用实例化圆片贴在沙床上，透明度压得很低——深色椭圆在浅色海床上会像污渍。

## 验证与边界

- 在 RTX 4060 上实测（关闭 vsync）：1440×900 约 478fps，1920×1080 约 352fps，2560×1440 约 235fps。
- 已在 1920×1080 宽屏、1090×915 竖屏、2x 高分屏、390×760 手机四种视口下截图验证，无控制台报错。
- **边界**：这是视觉演示，不是物理仿真。水深、岸线、鱼群游动都是程序化生成的示意，不对应任何真实海域；没有水下体积光、没有真实流体模拟、没有碰撞检测。
- **性能边界**：集成显卡或移动端会触发自适应降分辨率，画面会变软；着色器依赖 WebGL2 特性，极老的设备可能无法运行。
- 水面与沙滩在极浅水带（水深 < 0.1m）依靠颜色渐变衔接，快速拖拽视角时该处可能有轻微色带。
