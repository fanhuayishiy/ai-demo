# FIRELINK 当前版本复现提示

```text
制作一个面向消防专业交流与公众科普的中文实时 3D 模块化消防概念演示，品牌 FIRELINK。第一屏直接进入可交互的夜间微缩城市与指挥总览，不做营销落地页。主场景使用 Three.js / React Three Fiber，React + TypeScript 管理界面，Vite 构建；通过 ngraph.path 做道路图搜索，业务数据完全本地模拟。

画面采用正交斜俯视、全幅城市沙盘和紧凑指挥界面。暖色窗光、冷白站点灯、局部火光与烟雾共同照明，消防红、白色车身、青色供水和琥珀色救援标识相互区分。建筑有窗框、屋顶设备、道路和有限绿化，使用共享程序纹理与实例化细节；车辆具有可辨认的车厢、卷盘、支腿、设备和警示灯。桌面有右侧指挥详情及底部装备带，手机可折叠，标签避免遮挡面板。

重叠地面铺装按用途采用不同的固定深度偏移，保持材质不透明、深度测试和深度写入，不随斜视角放大偏移；站房屋顶面避开槽条占地，消除这些共面重叠来源。不要为修饰表面而改变实体高度、道路、泊位或作业路径。几何和材质配置可自动检查，但镜头运动下的实际闪烁仍需要浏览器验证。

设置三个分布式站点、两个虚构补水点、十二辆车和十类模块：三辆供水车，移动增压泵车、举高喷射车、能源车、机器犬车、工具车、灭火无人机机场车、侦查车、重载无人机车、云梯车各一辆。首批侦查与地面响应并行，疑似生命信号触发预案增援；生命线索必须人工复核，供水连接和救援也有授权条件。

重点展示同一根消防水带的分段承托，不把三架消防无人机做成三支独立水炮。机场车有三个真实停机位和卷盘，前两架白色托举机带吊架，最后一架红色无人机携带末端喷头。起飞偏移为0、7、14秒，单机垂直起飞4秒不相互重叠，随后沿分开的高度层与外侧航路飞行。两架托举机分别在出动16、23秒到位，末端机30秒到位。整条链路与待起飞尾段始终连在真实挂点上，水带连续放出、轻微下垂，经过侧向净空区域，不突然生成整段管线，也不穿过旋翼或车顶。只有全部就位且有供水时末端才喷水，按单喷头6 L/s虚构演示需求计入水量，失水时显示等待，故障和撤回时停喷回收。

移动增压车必须先到位并获授权，供水车才向其有限缓冲水箱供水；三辆供水车能够离开接口独立补水再回来。缓冲水箱不能无中生有，源头缺水会消耗储量并可能中断喷射，撤回增压车立即断开下游供水。道路、建筑、泊位、转向与水带接口使用统一空间布局。

重载无人机从自己的机场车起飞，经高处航路向实际屋顶接收区吊放四组器材，不投放到阳台；第34秒完成交接，第64秒普通物资任务正常回收。屋顶有四名独立受困人物、接应标线和工作灯。展示吊索放下、脱钩、收回和返航；未载人的中断任务从实际位置回收，载车等待飞行器降落及消防人员登车才允许移动。

独立的人员吊运前瞻分支默认关闭。“干预”页和C01详情提供“载重无人机吊人”操作区，显示阶段与不可执行原因。开启概念、复核生命线索后，允许明确授权本轮或下一次尚未开始的C01出动；提前授权不自动派车或恢复播放，只在物资交接后、出动第34至39秒接应窗口执行，错过窗口则拒绝。吊篮侧门展开，人物从实际开口登篮，保持完整尺寸随飞行器转运，在地面接应区离篮。吊运结果独立记录，不计入云梯转移统计，也不是主任务完成条件；常规两人救援仍由云梯推进。

吊运登篮前取消时，人物先退回屋顶，再收回空篮；登篮后取消、故障或撤回时，先完成地面交接和飞行器回收，再让消防人员登车并执行既有载车离场命令。取消、不可用、低电量和本轮结束清除待执行授权，恢复设备或重新出动不得沿用旧授权。不要让人物消失、缩小或瞬移，不把受控动画流程描述为真实故障下的安全保证。

七名消防人员随四辆车到场：P01搭载指挥员与观察联络员，M01搭载供水保障员，D01搭载机器犬操作员，C01搭载无人机操作员及两名地面接应员。驾驶室有可见坐姿、头盔、防护服和安全带；停车转向完成后错峰下车，按独立时序步行到地面岗位。上下车采用坐姿与门外站姿的简化切换，不假装已经模拟车门开合或踏板攀爬。撤回先返回登车，飞机回收和载人交接优先于C01人员登车；全员上车后车辆才移动。消防员全程在地面，屋顶只有四名受困人物，不虚构安全登顶通道。提前授权和普通物资航班不触发地面接人，只有实际载人接近才引导接应；选择消防员只关联装备或事件，不自动授权、派车或增加救援统计。

机器犬以队列从地面入口入内，承担搜索和携管，不能穿墙。提供对象选择、搜索、聚焦、跟随、缩放和显式开启的镜头巡览，以及暂停、0.5/1/2/4倍速、重新演示、单车撤回和故障开关。人工指挥和引导演示共用单一状态。全程最多180秒演示时间，任务结束后留在复盘；页面后台和减少动态效果偏好需要正确处理。

顶部“系统介绍”打开可滚动的文字弹窗，集中介绍十项系统设计优势及能力边界，支持键盘焦点、Escape与背景关闭。查看期间暂停演示，关闭后只恢复由该弹窗暂停的同一轮任务，不恢复原本就暂停或已经重置的任务。

写自动测试覆盖调度、供水、授权、交通、起降、真实挂点连接、管径间隙、召回连续性、屋顶物资交付、吊运提前请求与取消、人物转运、乘员错峰上下车与离场等待、介绍弹窗暂停所有权、地面深度层、屋顶重叠、界面与子目录部署。GitHub Pages必须使用相对资源路径，公开目录包含源码、测试、装备图片、锁文件、文档及新的dist，不包含node_modules、临时日志和本机路径。

所有时间、建筑、人物、流量和设备参数均为虚构。调度不是最优AI，生命线索不是隔墙透视，承托水管不是实际载荷认证，吊运不是已验证的人命救援能力。不要声称已经求解火灾、液压或软管动力学。浏览器无法验证时明确保留这一限制，不拿旧截图或单元测试充当最终视觉证明。
```
